# 文章比較 要件

元の企画書：[requirements.md](requirements.md)。技術構成は [software-stack.md](software-stack.md) を参照。

## 目的

- 2つの文章の違う箇所を、目で探さずに確かめる。契約書や手順書の新旧の比較、AI が書き直した文章の確認に使う。

## 利用者

- 本人と同僚。toolbox の一ツールとして `src/tools/index.ts` と直下の README に登録し、zip に入れて配る。

## 主要な利用の流れ

1. ツールを開き、「前の文章」と「後の文章」に文章を貼る（ホームで貼り付けた文章・置いたテキストファイルからも始められる）。
2. 両方に文章が入ると、違う箇所を色分けした結果が出る。
3. 前・次の違いへ移りながら確かめる。文章を直すと、結果も変わる。

## 扱う範囲 / 今は扱わないこと

扱う

- 2つの文章の貼り付けとテキストファイルの読み込み、前と後の入れ替え
- 行ごと、変わった行の中は文字（書記素）ごとの違いの表示（左右に並べる表示と、1つにまとめる表示）
- 違う箇所の数、前・次の違いへの移動、変わらない行の折りたたみ
- ホームで貼り付けた文章・置いたテキストファイル（1つか2つ）の受け取り

今は扱わない

- 空白・改行・全角と半角の違いを無視する比較（改行コードの違いだけは無視する）
- 単語ごとの比較など、英語などの文章への配慮
- 結果のファイルへの書き出し・印刷・コピー
- 3つ以上の文章の比較、Word・PDF などの文書ファイルの読み込み
- 貼った文章・結果の保存

## 必要な機能と主要な振る舞い

- **画面**：上に「前の文章」と「後の文章」の欄を左右に並べ、下に結果を出す。
- **比べる**：両方の欄に文章（空白以外の文字）が入ると比べる。打っている間は比べず、手を止めたら比べ直す。
  - 行ごとに差分を取り、変わった行のまとまりの中を文字（書記素）ごとに比べ直す。
  - 違いに挟まれた短い一致（両側の違いのどちらより長くないもの）は、1つの違いにまとめる。
  - 改行コード（CRLF・CR・LF）はそろえてから比べる。
- **結果**：前にだけある部分（削除）と、後にだけある部分（追加）を、色と線（取り消し線・下線）で区別して示す。改行の削除・追加は印で示す。
  - 左右に並べる表示では、前の文章を左、後の文章を右に、変わったまとまりの高さをそろえて並べる。片方にしかないまとまりは、もう片方を斜線で埋める。
  - 1つにまとめる表示では、前の文章の削除のすぐ後に、後の文章の追加を差し込む。
  - 変わらない行が長く続くところは、違いの前後3行だけを出して畳み、押すと開く。
  - 違う箇所の数を出す。続いている削除と追加は1か所と数える。前・次の違いへ移れる。
- **比べきれないとき**：画面を止める時間に上限を設ける。行の差分が時間内に終わらなければ結果を出さずに知らせ、変わった行の中の差分が終わらなければ行ごと入れ替わったものとして示し、その旨を出す。
- **受け取り**：ホームで貼り付けた文章・ツールの欄の外で貼り付けた文章は、空いている欄（前の文章から）に入れ、両方に入っていれば後の文章を置き換える。テキストファイルは欄に置けばその欄に、2つまとめて置けば更新日時の古いほうを前の文章にする。

## 完了条件

1. 「前の文章」と「後の文章」に貼ると、違う箇所が削除と追加で色分けされて出る。
2. 「甲は乙に支払う。」と「甲は丙に支払う。」を比べると、「乙」の削除と「丙」の追加だけを示し、1か所と数える。
3. 長い文章で、変わらない行を畳み、前・次の違いへ移れる。
4. ホームで文章を貼り付けると、行き先に文章比較が出る。テキストファイルを2つ置くと、文章比較で比べられる。
5. 貼った文章を保存せず、外部へ送らない。
