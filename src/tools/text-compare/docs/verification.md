## 比較処理の最小修正と一括クリアの追加（2026-10-18）

- 全体の期限を過ぎてもまとまりごとに最低5msを追加する処理を削除した。期限切れのまとまりは書記素への分割前に `rough` にし、分割後・区切りの組み立て中・短い一致の結合中にも期限を確かめる。
- 結合時の書記素数の再計算をやめ、差分の区切りに含まれる個数を加算して使うようにした。
- 右上に共通の `Button` を使った「すべてクリア」を追加した。前後の入力と結果、違いの選択、折りたたみの展開状態を一度に戻す。表示方式は保つ。
- `compare.test.ts` に、期限切れ後は追加の文字比較・書記素分割を行わず文章を復元できることと、短い一致の繰り返しでも書記素への分割量が入力の総量を超えないことの回帰テストを追加した。

今回の変更後はテスト・lint・型チェック・ビルドを実行していない。画面（開発サーバー・配布物・`file://`）、Windows の Edge・Mac の Chrome での確認と、長文の実際の停止時間の計測も未実施。上の成功記録は変更前のもの。

次に画面を確認するときは、以下を確かめる。

1. 前後の文章を入力し、違いへ移動して折りたたみを開いた後、「すべてクリア」で両方の入力と結果・違いの選択が消える。新しい文章を入れると、折りたたみは閉じた状態から始まる。
2. 片方だけ入力した場合と、空白・改行だけ入力した場合もまとめて消せる。両方とも空のときは「すべてクリア」が無効になる。
3. 入力後200ms以内にクリアしても、その後に古い結果が表示されない。クリア後は欄の外への貼り付けが再び「前の文章」に入る。
4. 変更行と一致行が交互に続く長文で、時間切れ後の変更箇所は行単位になる。「甲の」と「乙の」をそれぞれ繰り返した文章でも、比較が長時間止まらず、元の文章を欠落なく示す。
