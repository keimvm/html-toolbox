# 文章比較

2つの文章を貼り付けると、違う箇所を色分けして示すツールです。契約書や手順書の新旧の比較、AI が書き直した文章の確認に使えます。toolbox に含まれる単一 HTML のツールで、貼った文章を保存せず、外部へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../../README.md#使い始める)）、ホームから「文章比較」を選びます。ホームに文章を貼り付けて「別の文章と比べる」を選ぶか、テキストファイルを1つか2つ置いても始められます。
2. 上の左の「前の文章」に元の文章（旧版、書き直す前など）を、右の「後の文章」に比べる文章（新版、書き直した後など）を貼り付けます。
3. 両方に文章が入ると、下の「違い」に結果が出ます。文章を直すと、手を止めたところで結果も変わります。

### 結果の見方

- 赤い文字（取り消し線つき）：前の文章にだけある部分（削除）
- 緑の文字（下線つき）：後の文章にだけある部分（追加）
- 「↵」の印：改行の削除・追加
- 変わった行のまとまりには、左端に細い線が付きます。変わらない行が長く続くところは、違いの前後3行だけを出して畳みます。「変わらない ○ 行を表示」で開きます。
- 「違い」の見出しの横に、違う箇所の数が出ます。続いている削除と追加は1か所と数えます。上下の矢印で前・次の違いへ移れます。
- 右上の「並べる」は前と後を左右に並べ、「まとめる」は1つの文章に削除と追加を差し込んで示します。「入れ替える」で前の文章と後の文章を入れ替えます。

### 比べ方

- 行ごとに比べてから、変わった行の中を文字ごとに比べます。「𠮷」や絵文字のような文字も1文字として扱います。
- 違いに挟まれた短い一致（「の」「は」だけが一致する、など）は、読みやすいよう1つの違いにまとめます。
- 改行・空白・全角と半角の違いも違いとして示します。改行コード（Windows と Mac の違い）だけは違いにしません。
- 長く変わった箇所を時間内に文字ごとに比べきれないときは、行ごと入れ替わったものとして示し、その旨を出します。2つの文章が大きく違い比べきれないときは、結果を出さずに知らせます。

### 文章の入れ方

- 欄の外で貼り付けると、空いている欄（前の文章から）に入ります。両方に入っているときは、後の文章を置き換えます。ホームから渡したときも同じです。
- テキストファイル（.txt・.md など）をそれぞれの欄に置くと、その欄に入ります。2つまとめて置くと、更新日時の古いほうを前の文章にします。逆になったときは「入れ替える」を押してください。
- 欄の右上の「×」で、その欄の文章を消します。

## 開発する

開発サーバー・コマンドは [共通の開発・リリース手順](../../../docs/development.md#開発する) に従います。ツールを直接開くには `#/text-compare` を付けます。

| 場所 | 内容 |
| --- | --- |
| `compare.ts` | 行の差分、変わった行のまとまりの中の書記素の差分、短い一致のまとめ |
| `index.tsx`・`style.css` | ツールの定義（受け取れるもの・状態）と画面（2つの欄・結果の表示・前と次の違いへの移動） |
| `compare.test.ts` | 行と文字の差分、違う箇所の数、短い一致のまとめ、書記素、改行コード、結果から文章を組み立て直せること、打ち切り |

差分の本体は共通部品の [`src/engine/diff/`](../../engine/diff/)（Rust の WebAssembly）です。Rust が要ります（[開発する](../../../docs/development.md#開発する)）。

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
