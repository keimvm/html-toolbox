# PDF編集

PDF のページの削除・並べ替え・回転・結合と、ページの画像や文字の取り出し、ページの中の要素（画像・図形・文字）の削除ができるツールです。重い PDF を、文字を残したまま中の画像だけを縮めて小さくすることもできます。元の PDF は変更せず、編集結果を別のファイルとして保存します。PDF とその内容は外部へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../../README.md#使い始める)）、ホームから「PDF編集」を開きます。ホームに PDF を置いて「ページを編集する」を選んでも開けます。
2. 「PDFを選ぶ」か、画面へのドラッグ＆ドロップで PDF を読み込みます。
3. 中央のプレビューを縦にスクロールして読み進めます。表示位置に合わせて左のページ一覧の選択も切り替わります。左のページ一覧や、上の「∧」「∨」（前のページ・次のページ）からも移動できます。ページ一覧では矢印キーで前後のページを選べます。上部の「−」「＋」と倍率の選択で 25〜300% に拡大・縮小でき、「幅に合わせる」では表示領域に収めます。拡大してはみ出した部分は横にもスクロールできます。
4. 選択中のページを「回転」（右に90度）・「削除」し、ページ一覧のドラッグか「↑」「↓」で並べ替えます。ページ一覧では Delete キーでも削除できます。「元に戻す」（⌘Z / Ctrl+Z）で直前の操作を取り消せます。
5. 右上の「PDFを追加」で、別の PDF を末尾に結合します。複数のファイルも選べます。開いている間に画面へ PDF をドロップしても末尾に加わります。
6. 右上の「保存」で、全ページの PDF、または選択中のページの PNG・JPEG をダウンロードします。
7. 「画像・文字」を押すと、右に選択中のページの画像・文字・要素のパネルが開きます。

右上の「⋯」の「画像変換でページを画像にする」で、今のページの並びの PDF の各ページを、画像として画像変換の一覧に加えます。

### PDF を小さくする

PDF の中の写真・スキャン画像だけを、指定の解像度（dpi）まで縮めて JPEG にし直します。文字・図形はそのまま残り、選択・検索もできます。元の PDF は変更しません。

1. 次のどれかで「PDFを小さくする」の画面を開きます。
   - PDF を開いているとき：右上の「⋯」の「PDFを小さくする」。今のページの並び・回転・削除を反映した PDF が対象になります。
   - 最初の画面の「PDFを小さくする」。PDF を選ぶか、画面にドロップします。
   - ホームに PDF を1つ置き、「PDFを小さくする」を選ぶ。開いている PDF の編集とは別に、置いた PDF だけを小さくします。
2. 仕上がり（きれいめ 200 dpi・標準 150 dpi・小さめ 100 dpi）を選んで「小さくする」を押します。
3. 変換前後の容量を確かめてから「保存」します。「元の名前-縮小.pdf」の名前でダウンロードします。

- 透過のある画像、白黒2値の画像、回転・反転して置かれた画像、グループ（Form XObject）の中の画像、JPEG にしても1割以上小さくならない画像は、元のまま残します。
- ページの内容を作り直すため、PDF の作りによっては、しおり・フォーム・電子署名などが元の PDF と同じに残らない場合があります。保存した PDF を開いて確かめてください。
- 小さくした PDF は復元用データに入れません。保存する前にページを閉じようとすると、確認が出ます。

### 画像・文字のパネル

- **画像**：ページ直下の画像の見本と、画素数・配置の大きさ（mm）・縦横それぞれの実効解像度（dpi）を示します。「この画像を保存（PNG）」で元の画素数のまま保存します。選んだ画像は、プレビューに枠で示します。
- **文字**：ページに含まれる文字の情報を取り出して示します。コピーするか、UTF-8 のテキストとして保存できます。
- **要素**：ページ直下の要素（文字・図形・画像・グラデーション・グループ）の一覧です。選ぶとプレビューに枠を出します。「選んだ要素を取り除く」で、選んだ要素を除いたページに差し替えます。取り除いたあとも「元に戻す」で戻せ、元の PDF は変わりません。グループは中身ごと取り除きます（グループの中の要素だけは選べません）。

### 再読み込みとタブを閉じたとき

開いた PDF と編集の状態は、復元用としてブラウザーの中に自動で残します。ヘッダーに「再読み込みに対応」と出ていれば、再読み込みやタブを閉じたあとにまた開いたとき、PDF、ページの順・回転・削除・取り除いた要素、選択中のページ、倍率、直近50操作の取り消しの履歴を戻します。この記録は新しい版でも読めます。ページの中の細かなスクロール位置と、画像・文字のパネルの状態は戻しません。

「⋯」の「閉じる（復元用データも消す）」を押すと、復元用データも消します。PDF として手元に残す場合は「保存」を使ってください。復元用の保存中や保存に失敗したときは、ページを閉じる前の確認を出します。

復元できるのは同じブラウザー・同じプロファイルです。プライベートブラウズの終了やブラウザーの保存データの削除では復元できません。複数のタブで開くと、最後に保存したタブの状態が復元の対象になります。

ダウンロードの完了・キャンセルはアプリから確かめられないため、保存したあとも「未保存の変更」の表示と、閉じる前の確認を残します。保存したファイルを確かめてから閉じてください。編集を取り消して読み込んだときの内容に戻すと「変更なし」になります。

### 対応範囲

- 要素の一覧・画像の個別の取り出し・要素の削除は、ページ直下の要素が対象です。グループ（Form XObject）の中の画像は個別には扱えません。
- 個別の画像は元の画素数で PNG にします。マスク・切り抜き・複雑な色空間の見た目は、元の PDF と一致しない場合があります。
- 文字は PDF に含まれる文字の情報を取り出します。段組みの読み順・表の復元・OCR（スキャンした画像の文字の読み取り）は扱いません。
- 保存はページを組み直す方式です。しおり、電子署名、文書単位の付加情報の保持は保証しません。
- パスワードが必要な PDF は扱えません。1ファイル 150 MB まで。ページの描画は最大 1,600 万画素、個別の画像は 3,200 万画素までです。
- 日本語の代替フォントとして Noto Sans JP Regular を内蔵しています。埋め込まれていないフォントの字形や太さが元の文書と異なる場合があります。
- Markdown への変換と OCR は扱いません。

## 開発する

開発サーバー・コマンドは [共通の開発・リリース手順](../../../docs/development.md#開発する) に従います。ツールを直接開くには `#/pdf-edit` を付けます。

| 場所 | 内容 |
| --- | --- |
| `editor.ts` | ページの並び・回転・削除・結合・要素を取り除いたページへの差し替えと、取り消し（50操作） |
| `preview.ts` | プレビューの倍率と、スクロールに合わせて選ぶページ |
| `session-store.ts` | 復元用データ（IndexedDB `toolbox-pdf-edit`、固定のキー） |
| `index.tsx`・`style.css` | ツールの定義（受け取れるもの・状態）と画面 |
| `editor.test.ts`・`preview.test.ts`・`session-store.test.ts` | ページの操作・倍率・復元用データ（fake-indexeddb） |

PDF の処理は toolbox の共有の PDF エンジン（`src/engine/pdf/`）を使います。実際の PDF の保存と読み直し、要素の削除のテストと合成 PDF は `src/engine/pdf/` にあります。

個人・業務用の PDF は Git 管理対象外の `local-samples/` に置きます。共有のテストには合成データを使い、内容を外部サービスへ送信しないでください。

要件と当初の要望は [docs/RFP.md](docs/RFP.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
