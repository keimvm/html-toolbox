# タイピングゲーム（typing-game）

toolbox に加える HTML ツール。好きな文章を貼り付けて日本語入力（IME）で打ち、打ち終えるまでの時間と、見本と違う箇所を確かめられるようにする。

## 目的・背景

- 好きなときに、思い立ったらすぐタイピング練習をしたい。
- 練習問題を前もって用意する手間をなくしたい。そのため、そのとき手元にある任意の文章を貼り付けて、それを見本にする。

## 実現したい状態

- 使う人が文章を貼り付けると、その文章を見本として打ち始められる。
- 開始ボタンを押すと3秒のカウントダウンがあり、それが終わるとタイマーが動き出す。
- 打ち終えたら Esc キーを押して終える。Esc キーが終了ボタンの役目をし、押すとタイマーが止まり、結果が出る（最後の文字の確定で自動的に止める案は取りやめた）。
- 変換中（まだ確定していない文字があるとき）の Esc キーは、普段どおり変換の取り消しになり、終了にはならない。終了になるのは、確定した後に押した Esc キーだけ。
- 画面上の終了ボタンは置かず、「確定後に Esc で終了」の案内を画面に出す。
- 打ち方は、普段どおり日本語入力（IME）で変換して確定する形。漢字まじりの文章をそのまま見本にできる（ローマ字で読みを打つ形ではない）。
- 打っている途中は判定で止められず、最後まで打ち切れる。
- 画面は、左に見本（貼り付けた文章）、右に入力する場所を並べる。
- 打っている途中は、左の見本側で、打ち終えた所まで文字の色が変わっていく。変換中の文字は数えず、確定のたびにまとめて進む。
- 打ち終えたら、かかった時間と、見本と違う箇所（間違えた箇所）が分かる。違う箇所は、右の入力側で赤く示す。打っている途中は、違う箇所を色で示さない。

## 扱う範囲 / 今は扱わないこと

扱う

- 文章の貼り付け
- IME で確定した文字を見本と照らし合わせる判定（打ち終えた後にまとめて）
- 打ち終えるまでの時間の計測
- 結果として、かかった時間と間違えた箇所の表示
- toolbox の zip に入れて同僚にも配る

今は扱わない

- 1分あたりの文字数のような速さの目安
- 過去の結果を残して、前回と比べること
- 貼った文章を練習問題として保存し、また使うこと
- 英語など日本語以外の文章への配慮
- ローマ字で読みを打つ形の練習
- 変換前の読みの打ち間違いの判定（判定するのは確定した文字だけ）
- 改行・空白、全角・半角の打ち分けの判定

## 大切にしたいこと・制約

- 開いてすぐ打ち始められる手軽さ。
- 打っているときの気持ちよさ・爽快さを感じられる画面と操作。具体的には、打った文字が色を変えながら進んでいく感覚。
- toolbox 全体の約束を守る：インストール不要、ネットにつながらない状態でも動く、`file://` で開いて使える、Windows と Mac の Chrome・Edge で動く。

## 完了条件

- 文章を貼り付けて開始し、IME で最後まで打ってから Esc キーを押すと、かかった時間と見本と違う箇所が表示される。（推定）
