# プロンプト集

AI チャットでよく使うプロンプトをためておき、タグで絞り込んで「コピー」ですぐ貼れるようにするツールです。プロンプトは自分で選んだ PC のフォルダにファイルとして保存し、外部へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../../README.md#使い始める)）、ホームから「プロンプト集」を選びます。
2. 初回は「保存先のフォルダを選ぶ」を押し、プロンプトを保存するフォルダを選びます。ブラウザーが編集の許可を求めたら許可します。フォルダに `prompt-library.json` がなければ作り、あれば読み込みます。
3. 右上の「新しいプロンプト」で、タイトル・概要・本文・タグを入れて「追加」します（⌘+Enter / Ctrl+Enter でも追加できます）。概要は一覧のカードに出す短い説明で、空なら本文の先頭が出ます。タグは空白・カンマ・読点で区切ります。概要とタグはなくても保存できます。使っているタグは入力欄の下から選べます。
4. 使うときは、上の「タグ」からタグを選んで絞り込み、目的のプロンプトの「コピー」を押して AI チャットに貼ります。カードにはタイトルと概要が出ます。一覧の上から9件までは、数字キー（`1`〜`9`）でもコピーできます。
5. 直すときは「編集」を押します。削除は編集画面の「削除」から、確認のうえで行います。

ホームに文章を貼り付けて「プロンプトとして残す」を選ぶと、その文章を本文にした新しいプロンプトの編集画面が開きます。ホームにフォルダを置いて「プロンプトの保存先にする」を選ぶと、そのフォルダを保存先にできます。

### 保存のしかた

- 編集画面の「追加」「保存」、削除の確認の「削除する」、並び替え・表示の切り替え、インポートの確定の時点で、`prompt-library.json` に書き込みます。画面全体の保存ボタンはありません。
- 書き込む直前にファイルを読み直し、その内容に変更を加えて書き込みます。同じフォルダを別のタブでも開いている場合、ほかのタブで加えた変更を消しません。画面に戻ったときも、ファイルの内容で一覧を更新します。
- `prompt-library.json` が壊れている・形式が違うなどで読めない場合は、ファイルを上書きせず理由を表示します。直したあとに「もう一度開く」を押すか、別のフォルダを選んでください。
- 編集画面で入力した内容を保存せずに閉じようとすると、捨ててよいかを確かめます。

### 次回から

選んだフォルダはブラウザーが覚え、新しい版でも引き継ぎます。次に開いたとき、許可が残っていればそのまま一覧が出ます。出ない場合は「前回のフォルダ（名前）を開く」を押し、ブラウザーが求めればアクセスを許可します。

保存先を変えるときは、右上のフォルダ名のメニューから「別のフォルダを選ぶ」を選びます。前のフォルダの `prompt-library.json` はそのまま残ります。同じメニューの「ファイルを読み直す」で、ファイルの最新の内容を読み込めます。

### 絞り込み

- 使っているタグが名前順に並びます。複数選ぶと、選んだタグを**すべて**含むプロンプトだけが出ます。カードのタグを押しても絞り込めます。
- 「絞り込みを解除」で全件に戻ります。

### 並び替えと表示・非表示

- 一覧の右上の「並び替え・表示」を押すと、プロンプトが1行ずつ並びます。行をドラッグするか ↑↓ のボタンで並べ替えます。一覧と数字キーの順はこの並び順です。
- 「表示」「非表示」のボタンで、一覧に出すかを切り替えます。非表示にしたプロンプトは一覧と数字キーの対象から外れ、件数の横に「非表示 N件」と出ます。並び替え・表示の画面では編集・削除もできます。
- 「タイトル順に並べ直す」で、全体をタイトル順にできます。変更はすぐ保存されるので、終わったら「完了」を押して一覧に戻ります。
- 新しく追加したプロンプトは末尾に入ります。

### エクスポートとインポート

右上のフォルダ名のメニューから行います。

- **エクスポート（JSON をダウンロード）**：今のプロンプトをすべて（非表示のものも含め）`prompt-library-年-月-日.json` としてダウンロードします。バックアップや、別の PC・フォルダへの移し替えに使えます。
- **インポート（JSON から読み込む）**：エクスポートしたファイル（または別のフォルダの `prompt-library.json`）を選ぶと、「追加する」か「上書きする」かを確かめます。
  - 追加する：今のプロンプトの末尾に足します。タイトル・概要・本文・タグが同じものがすでにあれば足しません。
  - 上書きする：今のプロンプトをすべて消し、読み込んだものに置き換えます。元に戻せないため、心配なときは先にエクスポートしてください。
- 読めない・形式の違うファイルは取り込まず、理由を表示します。

### 以前の版との行き来

概要・並び替え・表示の切り替えを入れた版（2026年10月）から、`prompt-library.json` の形式が新しくなりました。以前の形式のファイルはそのまま読め、一覧はそれまでと同じタイトル順で始まります。新しい版で一度でも書き込むと、以前の版の toolbox ではそのファイルを開けなくなります（壊れたとは扱わず、新しい版で開くよう案内します）。

### 一部を書き換えるプロンプト

「〇〇について要約して」のように毎回変わる部分があるプロンプトは、そのまま保存し、貼った後に AI チャット側で書き換えます。本文に `〇〇` などの目印を入れておくと探しやすくなります。

### 使えない・うまく動かないとき

- 「このブラウザーではフォルダを使えません」と出る場合は、Chrome または Edge（129 以降）で開いてください。
- 「コピーできませんでした」と出る場合は、「編集」で本文を開き、選択してコピーしてください。
- 会社の管理設定でフォルダの読み書き（File System Access API）が止められている場合は使えません。

## 開発する

開発サーバー・コマンドは [共通の開発・リリース手順](../../../docs/development.md#開発する) に従います。ツールを直接開くには `#/prompt-library` を付けます。

| 場所 | 内容 |
| --- | --- |
| `library.ts` | 保存ファイルの形（検査・書き出し・版1の読み込み）、タグの入力の区切り、AND の絞り込み、追加・編集・削除、並び替え・表示の切り替え、インポートの追加・上書き |
| `storage.ts` | File System Access API での保存ファイルの作成・読み込み・書き込み（書き込み直前の読み直し） |
| `folder-memory.ts` | 保存先のフォルダの記録（`src/lib/idb.ts` で IndexedDB に固定のキーで保存） |
| `index.tsx`・`style.css` | ツールの定義（受け取れるもの・状態）と画面 |
| `library.test.ts`・`storage.test.ts` | 絞り込み・並び替え・インポート・保存ファイルの読み書き（ファイル API は模擬） |

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
