# 画像変換

写真やスクリーンショットの大きさ・容量・形式を変えて、メールや社内システムに添付できるファイルにするツールです。仕上がりの容量と見た目をその場で確かめながら保存できます。画像をまとめて PDF にすること、PDF のページを画像にすること、重い PDF を PDF のまま小さくすることもできます。画像と PDF をこの PC の外へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../../README.md#使い始める)）、ホームから「画像変換」を選びます。
2. 「画像・PDFを選ぶ」で写真やスクリーンショットをまとめて選ぶか、画面にドロップします。⌘V（Windows は Ctrl+V）でスクリーンショットなどの画像を貼り付けても加えられます。一覧に並びます。
3. 上の「全体の設定」で、出力形式（JPEG・PNG）、1枚あたりの上限、長い辺の px を決めます。全部の画像に当たり、一覧に変換後の大きさ・容量と見本が出ます。上限に収まらない画像には「上限を超えています」の印が付きます。
4. 気になる画像は「確かめる・直す」（または見本）を押して開きます。元の画像と変換後を並べて、全体・100%・200% で見比べられます。この画像だけ形式・長い辺・画質を変えたり、回転・切り抜き・塗りつぶしをしたりできます。
5. 「この画像を保存」か、一覧の「保存」「すべて保存」でダウンロードします。

最初の設定は JPEG・上限 1 MB・長い辺 1920 px です。上限を空にすると上限なし、長い辺を空にすると元の大きさのままになります。ページを開き直したときは、この設定に戻ります。

ホームに画像や PDF を置いても始められます。画像を2枚以上置いたときは「まとめて1つのPDFにする」、PDF を1つ置いたときは「PDFを小さくする」も選べます。

### 容量と画質

- JPEG は、上限に収まる最も高い画質を 30〜90 の中から自動で選びます。上限がないときは画質 90 です。
- 画質 30 でも収まらない画像には印が付きます。長い辺を小さくするか、個別の画面で長い辺や画質を下げてください。
- PNG は画質の段階がないため、自動では合わせません。上限を超えたら印が付きます。容量を減らすには長い辺を小さくするか、JPEG にします。
- 上限・容量は 1 KB = 1,000 バイト、1 MB = 1,000,000 バイトで数えます。添付先が 1,024 バイト単位で数えていても、収まる側にずれます。
- 画像は拡大しません。長い辺が設定より小さい画像は、元の大きさのままです。

### 個別の画面

- **見比べる**：左が元の画像（回転・切り抜き・塗りつぶしの前）、右が保存する画像です。100%・200% は変換後の画素数が基準で、元の画像も同じ部分が同じ大きさに見えるよう並べます。片方をスクロールすると、もう片方も同じ場所を表示します。
- **切り抜く**：画像の上をドラッグして、残す範囲を囲みます。囲み直すと範囲が変わります。「切り抜きを解除」で元に戻ります。
  - 範囲のすぐ外（上、入らなければ下）に、大きさ（px）と縦横比（「1:1 正方形」「16:9」、割り切れない比は「約 1.33:1」）を表示します。回転したあとの向きで数えます。
  - 囲んだあとは、矢印キーで範囲を 1 px ずつ動かせます。Shift を押しながら矢印キーを押すと、左上を動かさずに幅（←→）・高さ（↑↓）を 1 px ずつ変えます。1 px は元の画像の画素です。
- **塗りつぶす**：ドラッグで囲んだ範囲を黒く塗りつぶします。何か所でも塗れます。「塗りを1つ戻す」で最後に塗った範囲を消します。保存する画像には、塗りつぶした部分の元の画素は残りません。
- 「左に回す」「右に回す」で90度ずつ回します。
- 形式・長い辺・画質を変えると、この画像だけに効きます。「全体の設定に戻す」で個別の設定を消します（回転・切り抜き・塗りつぶしはそのまま）。画質のつまみを動かすには、「上限に合わせて自動で決める」を外します。
- 右上の「‹」「›」（前の画像・次の画像）で、開いたまま隣の画像に移れます。

### PDF

- **PDF のページを画像にする**：「画像・PDFを選ぶ」で PDF を選ぶか、ドロップします。各ページを 200 dpi 相当の画像にして一覧に並べます（「報告書-p01」のような名前）。あとは写真と同じく全体の設定・個別の画面で扱い、保存します。フォントを含まない日本語の PDF でも、内蔵の日本語フォント（Noto Sans JP）で文字を描きます。
- **画像をまとめて PDF にする**：「PDFにまとめる」で、一覧の画像を今の設定で変換したものを、一覧の順に1枚1ページで並べた PDF を作ります。ページは画像と同じ縦横比で余白はなく、1 px を 0.75 pt（96 dpi）とします。できた PDF の容量を確かめてから「保存」します。「PDF編集で開く」を押すと、まとめた PDF を PDF編集でそのまま並べ替えたり回したりできます。
- **PDF を小さくする**：右上の「PDFを小さくする」で PDF を選び（ドロップも可）、仕上がり（きれいめ 200 dpi・標準 150 dpi・小さめ 100 dpi）を選んで「小さくする」を押します。PDF編集の「画像変換で小さくする」からも開けます。PDF の中の写真・スキャン画像だけを、指定の解像度（dpi）まで縮めて JPEG にし直します。文字・図形はそのまま残り、選択・検索もできます。変換前後の容量を確かめてから「保存」します。
  - 透過のある画像、白黒2値の画像、回転・反転して置かれた画像、グループ（Form XObject）の中の画像、JPEG にしても1割以上小さくならない画像は、元のまま残します。
  - ページの内容を作り直すため、PDF の作りによっては、しおり・フォーム・電子署名などが元の PDF と同じに残らない場合があります。保存した PDF を開いて確かめてください。
  - パスワードが必要な PDF は扱えません。

### 保存と付加情報

- 保存はすべてダウンロードです。元のファイルは変更しません。画像は「元の名前-変換.jpg」、PDF のページは「PDFの名前-p01.jpg」、まとめた PDF は「画像まとめ.pdf」、小さくした PDF は「元の名前-縮小.pdf」の名前で保存します。同じ名前のファイルがあると、ブラウザーが名前に番号を付けます。
- 「すべて保存」では、ブラウザーが複数のファイルのダウンロードを許可するか確かめることがあります。許可してください。
- 書き出す画像には、位置情報・撮影日時・カメラ情報などの付加情報（Exif）を一切残しません。写真の向きは、読み込むときに見た目どおりに直してから書き出します。
- 作業内容はブラウザー内に残しません。ほかのツールへ移っても作業は残りますが、ページを閉じる・再読み込みすると消えます。保存していない変換結果があるうちにページを閉じようとすると、確認が出ます。

### 開けないファイル

HEIC（iPhone の写真）など、ブラウザーが開けない形式は「この形式は開けません」と一覧に出ます。ほかの画像の作業はそのまま続けられます。HEIC は JPEG に書き出してから選んでください。

## 開発する

開発サーバー・コマンドは [共通の開発・リリース手順](../../../docs/development.md#開発する) に従います。ツールを直接開くには `#/image-converter` を付けます。

| 場所 | 内容 |
| --- | --- |
| `settings.ts` | 全体・個別の設定、上限と長い辺の読み取り、ファイル名の拡張子 |
| `fit.ts` | 上限に収まる最も高い JPEG の画質を二分探索で選ぶ |
| `geometry.ts` | 回転・切り抜き・塗りつぶしの座標（元の画像の座標と、回した画像の座標の行き来）、縮めた大きさ |
| `convert.ts` | Canvas での描画（塗りつぶし → 切り抜き → 回転 → 縮小）と JPEG・PNG の書き出し、一覧の見本 |
| `items.ts` | 一覧の画像と、1枚ずつ変換し直す順番待ち |
| `detail.tsx` | 個別の画面（見比べとスクロールの同期、切り抜き・塗りつぶしの操作、個別の設定） |
| `index.tsx`・`style.css` | ツールの定義（受け取れるもの・状態）、一覧・全体の設定・PDF のダイアログ・ドロップと貼り付けの受け付け |
| `settings.test.ts`・`geometry.test.ts` | 設定の読み取り・画質の選び方・座標の計算 |

PDF の処理は toolbox の共有の PDF エンジン（`src/engine/pdf/`）を使います。そのテストと合成データ（JPEG・PNG・写真入りの PDF）は `src/engine/pdf/` にあります。

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
