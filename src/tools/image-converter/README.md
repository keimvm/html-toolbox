# 画像変換

写真やスクリーンショットの大きさ・容量・形式を変えて、メールや社内システムに添付できるファイルにするツールです。矢印・枠・文字・番号を書き込んだり、見せたくない部分を黒く隠したりして、そのままコピー・保存できます。仕上がりの容量と見た目をその場で確かめられます。画像をまとめて PDF にすること、PDF のページを画像にすることもできます。重い PDF を PDF のまま小さくするのは [PDF編集](../pdf-edit/README.md#pdf-を小さくする) で行います。画像と PDF をこの PC の外へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../../README.md#使い始める)）、ホームから「画像変換」を選びます。
2. 「画像・PDFを選ぶ」で写真やスクリーンショットを選ぶか、画面にドロップします。⌘V（Windows は Ctrl+V）でスクリーンショットを貼り付けても加えられます。加えた画像がすぐに中央に大きく開きます。
3. 必要なら、上の道具で矢印・枠・文字などを書き込み、切り抜き・回転をします。
4. 右の「すべての画像」で、形式（自動・JPEG・PNG）、1枚あたりの上限、長い辺の px を決めます。「この画像」に、保存する画像の容量と上限に対する目盛りが出ます。
5. 「コピー」でクリップボードに入れてメールやチャットに貼り付けるか、「この画像を保存」でダウンロードします。2枚以上あるときは、右上の「すべて保存」でまとめてダウンロードできます。

画面は3つに分かれています。

- **左：画像の列**。加えた画像が並び、押すとその画像を開きます。各画像に保存する容量と、上限を超えた・保存したなどの印が出ます。ドラッグで並べ替えられます（PDF にまとめるページの順になります）。下に合計の容量が出ます。列の中では ↑↓ キーで前後の画像に移れます。
- **中央：編集**。上に道具と色・大きさ、取り消し・回転のボタン、その下に今の道具の使い方が出ます。右上の「編集」「見比べる」で表示を切り替えます。
- **右：仕上がり**。上から、すべての画像に当たる条件、開いている画像の容量・大きさ・形式、この画像だけの設定、コピー・保存のボタンです。

最初の設定は形式が自動・上限 1 MB・長い辺 1920 px です。上限を空にすると上限なし、長い辺を空にすると元の大きさのままになります。ページを開き直したときは、この設定に戻ります。

ホームに画像や PDF を置いても始められます。画像を2枚以上置いたときは「まとめて1つのPDFにする」（置いた画像を一覧に加え、その画像だけで PDF を作る。一覧にすでにある画像は入れない）も選べます。

### 書き込む

道具は左から次のとおりです。かっこの中は、押すとその道具になるキーです。

| 道具 | 使い方 |
| --- | --- |
| 選ぶ（V） | 書き込みをクリックで選び、ドラッグで動かします。四隅・両端の丸をドラッグすると大きさが変わります |
| 切り抜く（C） | 残す範囲をドラッグで囲みます |
| 矢印（A） | ドラッグで引きます。離したところが矢じりの先です |
| 四角で囲む（R）・丸で囲む（O） | ドラッグで枠を描きます |
| 文字（T） | クリックした場所に書きます。Enter で改行、Esc か外側のクリックで確定します |
| 番号（N） | クリックするたびに 1, 2, 3… の丸い番号を置きます。手順の説明に使えます |
| 蛍光ペン（H） | 囲んだ範囲に色を重ねます。下の文字は透けて読めます |
| 黒で隠す（B） | 囲んだ範囲を黒く塗りつぶします |

- **色と大きさ**：色は赤・黄・緑・青・黒・白、大きさ（線の太さ・文字と番号の大きさ）は小・中・大から選びます。選んだ書き込みがあればその書き込みが変わり、次に描く書き込みにも使います。太さ・大きさは画像の大きさに合わせて決まるため、大きな写真でも小さなスクリーンショットでも同じくらいの見え方になります。
- **描いたあと**：描いた書き込みは選ばれた状態になり、そのまま動かしたり色を変えたりできます。ほかの道具のままでも、書き込みの上をドラッグすると動かせます（蛍光ペンと黒塗りは、「選ぶ」か同じ道具のときだけ。上から別の書き込みを描けるようにするため）。文字は、文字の道具ではクリック、ほかの道具ではダブルクリックで書き直せます。
- **Shift**：押しながらドラッグすると、矢印は 45° ずつ、枠・切り抜きは正方形・正円になります。
- **キー**：Delete（または Backspace）で選んだ書き込みを消します。矢印キーで選んだ書き込みを 1 px（Shift で 10 px）ずつ動かします。黒塗りは元の画像の整数画素で動かし、移動だけでは範囲の大きさを変えません。Esc で選ぶのをやめます。
- **取り消し**：⌘Z（Windows は Ctrl+Z）で元に戻し、⇧⌘Z（Windows は Ctrl+Y）でやり直します。書き込み・切り抜き・回転を、画像ごとに 100 回まで戻せます。
- **番号**は描いた順に振ります。途中の番号を消すと、後ろの番号を詰めます。
- **黒塗り**：保存する画像には、塗りつぶした部分の元の画素は残りません。範囲は画素の境目まで外側へ広げて塗ります。
- 書き込みの文字と番号は、画像を回しても立てたまま描きます。書き込みは、保存する画像の大きさに縮めた後に描くため、縮めても線と文字がぼけません。

### 切り抜く・回す

- 「切り抜く」の道具では、画像の全体が出ます。ドラッグで残す範囲を囲み、四隅の丸で大きさ、内側のドラッグで位置を変えます。ほかの道具に切り替えると、切り抜いた範囲が大きく出ます。「切り抜きを解除」で元に戻ります。
  - 範囲のすぐ外（上、入らなければ下）に、大きさ（px）と縦横比（「1:1 正方形」「16:9」、割り切れない比は「約 1.33:1」）を表示します。回転したあとの向きで数えます。
  - 囲んだあとは、矢印キーで範囲を 1 px ずつ動かせます。Shift を押しながら矢印キーを押すと、左上を動かさずに幅（←→）・高さ（↑↓）を 1 px ずつ変えます。1 px は元の画像の画素です。Delete で切り抜きを解除します。
- 道具の右の回転のボタンで、左・右に90度ずつ回します。

### 見比べる

右上の「見比べる」で、表示を左右に分け、左に元の画像（切り抜き・回転・書き込みの前のまま）、右に保存する画像を並べます。圧縮や縮小でどこが粗くなったか、書き込み・切り抜き・回転でどう変わったかを確かめます。全体・100%・200% を選べ、100%・200% は保存する画像の画素が基準で、元の画像も同じ割合の大きさで出します。拡大したときは、どちらかの欄をドラッグ（またはスクロール）すると表示する場所が動き、もう片方の欄も同じ場所を見せます。狭い画面（幅 640px 以下）では上下に並べます。

### 容量と画質

- 形式が**自動**のときは、画像ごとに PNG と JPEG を試し、PNG が上限に収まり、最高の画質の JPEG の 1.5 倍までなら PNG にします。スクリーンショット・図・書き込みの文字はくっきりした PNG に、写真は小さな JPEG になります。どちらにしたかは「この画像」の形式に出ます。
- JPEG は、上限に収まる最も高い画質を 30〜90 の中から自動で選びます。上限がないときは画質 90 です。
- 画質 30 でも収まらない画像には印が付きます。長い辺を小さくするか、「この画像だけ変える」で長い辺や画質を下げてください。
- PNG は画質の段階がないため、自動では合わせません。上限を超えたら印が付きます。容量を減らすには長い辺を小さくするか、JPEG にします。
- 上限・容量は 1 KB = 1,000 バイト、1 MB = 1,000,000 バイトで数えます。添付先が 1,024 バイト単位で数えていても、収まる側にずれます。
- 画像は拡大しません。長い辺が設定より小さい画像は、元の大きさのままです。

### この画像だけ変える

右の「この画像だけ変える」を開くと、形式・長い辺・画質をこの画像だけ変えられます。「すべての画像と同じに戻す」で個別の設定を消します（書き込み・切り抜き・回転はそのまま）。画質のつまみを動かすには、「上限に合わせて自動で決める」を外します。画質を手で決めると JPEG で保存します。

### コピーと保存

- **コピー**（⌘C、Windows は Ctrl+C）：保存する画像と同じ大きさ・書き込みの画像を、クリップボードに入れます。メール・チャット・資料にそのまま貼り付けられます。ブラウザーがクリップボードに入れられる画像は PNG だけのため、JPEG で保存する画像も、劣化のない PNG にしてコピーします（貼り付け先によっては、上限より大きくなることがあります。容量を守るときは保存してから添付してください）。
- **保存**（⌘S、Windows は Ctrl+S）：保存はすべてダウンロードです。元のファイルは変更しません。画像は「元の名前-変換.jpg」、PDF のページは「PDFの名前-p01.jpg」、まとめた PDF は「画像まとめ.pdf」の名前で保存します。同じ名前のファイルがあると、ブラウザーが名前に番号を付けます。
- 「すべて保存」では、ブラウザーが複数のファイルのダウンロードを許可するか確かめることがあります。許可してください。
- 書き出す画像には、位置情報・撮影日時・カメラ情報などの付加情報（Exif）を一切残しません。写真の向きは、読み込むときに見た目どおりに直してから書き出します。
- 作業内容（書き込みを含む）はブラウザー内に残しません。ほかのツールへ移っても作業は残りますが、ページを閉じる・再読み込みすると消えます。保存していない変換結果があるうちにページを閉じようとすると、確認が出ます。入力中の文字や、変更後の変換を待っている間も未保存として扱います。
- 一覧から外すには、左の列の画像の「×」を押します。右上の「…」の「一覧の画像をすべて消す」で全部を外せます。

### PDF

- **PDF のページを画像にする**：「画像・PDFを選ぶ」で PDF を選ぶか、ドロップします。各ページを 200 dpi 相当の画像にして一覧に並べます（「報告書-p01」のような名前）。あとは写真と同じく書き込み・設定をして保存します。フォントを含まない日本語の PDF でも、内蔵の日本語フォント（Noto Sans JP）で文字を描きます。
- **画像をまとめて PDF にする**：右上の「PDFにまとめる」で、一覧の画像を今の設定・書き込みで変換したものを、左の列の順に1枚1ページで並べた PDF を作ります。ページは画像と同じ縦横比で余白はなく、1 px を 0.75 pt（96 dpi）とします。できた PDF の容量を確かめてから「保存」します。「PDF編集で開く」を押すと、まとめた PDF を PDF編集でそのまま並べ替えたり回したりできます。
- **PDF を小さくする**：PDF のまま中の写真・スキャン画像を縮めるのは、[PDF編集](../pdf-edit/README.md#pdf-を小さくする) の「PDFを小さくする」で行います。

### 開けないファイル

HEIC（iPhone の写真）など、ブラウザーが開けない形式は、左の列に「開けません」と出て、開くと理由が表示されます。ほかの画像の作業はそのまま続けられます。HEIC は JPEG に書き出してから選んでください。

## 開発する

開発サーバー・コマンドは [共通の開発・リリース手順](../../../docs/development.md#開発する) に従います。ツールを直接開くには `#/image-converter` を付けます。

| 場所 | 内容 |
| --- | --- |
| `settings.ts` | 全体・個別の設定（形式は自動・JPEG・PNG）、上限と長い辺の読み取り、ファイル名の拡張子 |
| `fit.ts` | 上限に収まる最も高い JPEG の画質を二分探索で選ぶ。形式が自動のとき PNG にするかの判定 |
| `geometry.ts` | 回転・切り抜きの座標（元の画像の座標と、回した・切り抜いた画像の座標の行き来）、編集の画面の座標（`viewTransform`）、Shift での正方形・45°、縮めた大きさ |
| `marks.ts` | 書き込みの形（矢印・枠・文字・番号・蛍光ペン・黒塗り）、太さ・大きさ、重ねる順、番号の振り方、当たり判定、つまみ |
| `paint.ts` | 書き込みを Canvas に描く（保存する画像と編集の画面で同じ描き方） |
| `history.ts` | 画像ごとの編集の取り消し・やり直し |
| `convert.ts` | Canvas での描画（黒塗り → 切り抜き → 回転 → 縮小 → 書き込み）と JPEG・PNG の書き出し、形式の自動選択、一覧の見本、コピー用の PNG |
| `items.ts` | 一覧の画像と並べ替え、1枚ずつ変換し直す順番待ち |
| `editor.tsx` | 中央の編集（道具・書き込みの操作・文字の入力・切り抜き・見比べ・キー操作）と、右のパネルの「この画像」 |
| `index.tsx`・`style.css` | ツールの定義（受け取れるもの・状態）、画面の配置、左の画像の列、右のパネルの「すべての画像」、PDF のダイアログ、ドロップと貼り付けの受け付け |
| `*.test.ts` | 設定の読み取り・画質と形式の選び方・座標の計算・書き込みの形と当たり判定・取り消し・並べ替え |

PDF の処理は toolbox の共有の PDF エンジン（`src/engine/pdf/`）を使います。そのテストと合成データ（JPEG・PNG・写真入りの PDF）は `src/engine/pdf/` にあります。画像のコピーは `src/lib/clipboard.ts` の `copyImage()`、道具のアイコンは `src/ui/icons.tsx` にあります。

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
