# 画像変換ツール 要件

元の企画書：[requirements.md](requirements.md)。技術構成は [software-stack.md](software-stack.md) を参照。

## 目的

- 容量が大きくてメールや社内システムに添付できない画像を、容量と見た目をその場で確かめながら、添付できるファイルにする。重い PDF を PDF のまま小さくするのは、2026-10-18 から PDF編集で行う。

## 利用者

- 未確認（本人だけか、同僚にも配るか）。toolbox の一ツールとして zip に入れて配れる形で作る。

## 主要な利用の流れ

1. 写真・スクリーンショットを数枚から十数枚まとめて選ぶか、ドロップ・貼り付けする → 一覧に並び、最初の画像が大きく開く。
2. 全体の設定（出力形式、1枚あたりの容量の上限、長い辺の px）を一度指定する → 全画像に当たり、一覧に各画像の変換後の容量と見本が出る。上限に収まらない画像には印が付く。
3. 気になる画像だけを開き、拡大して元と見比べる。その画像だけ画質・大きさ・形式を変えたり、切り抜き・回転・黒塗りをしたりする。
4. 説明に使う画像（おもにスクリーンショット）には、矢印・枠・文字・番号・蛍光ペンで書き込む。
5. 各画像の「保存」か「すべて保存」でダウンロードする。メールやチャットに貼るだけなら、「コピー」でクリップボードに入れる。

PDF は次の二つの使い方をする。

- 一覧の画像をまとめて1つの PDF にする。
- PDF のページを画像（JPEG・PNG）にする。

## 扱う範囲 / 今は扱わないこと

扱う

- 画像のリサイズ・圧縮・形式変換。読み込みはブラウザーが開ける形式（JPEG・PNG・WebP・GIF・BMP など）、出力は JPEG・PNG
- 付加情報（Exif。位置情報・撮影日時・カメラ情報など）の削除
- 切り抜き・回転、画面の一部の塗りつぶし（黒塗り）
- 書き込み：矢印、四角・丸の枠、文字、番号（1, 2, 3…）、蛍光ペン。色・大きさの変更、選んで動かす・大きさを変える・消す、取り消し・やり直し（2026-10-18 に追加）
- 保存する画像のクリップボードへのコピー（PNG）
- 一覧の画像の並べ替え（PDF にまとめるページの順）
- 画像 → PDF、PDF → 画像

今は扱わない

- ファイル名の付け直し
- PDF の編集（ページの削除・並べ替えなど）。PDF編集ツールで行う
- 重い PDF を PDF のまま小さくすること。PDF の作業として PDF編集ツールで行う（2026-10-18 に移した）
- WebP・AVIF の出力。添付先で開けない場合があるため
- HEIC（iPhone の写真）の読み込み。専用ライブラリの大きさとライセンスの負担が重いため
- 付加情報の一部（撮影日時など）だけを残すこと
- 作業状態の保存・再読み込み後の復元
- zip にまとめての保存
- 書き込みの手書きの線、モザイク・ぼかしでの隠し方。モザイク・ぼかしは元の画素の情報が残り、文字は読み取られる場合があるため、隠すのは黒塗りだけにする
- 書き込みの色・大きさの選択や、よく使う書き込みを覚えておくこと（作業状態を残さない方針に合わせる）

## 必要な機能と主要な振る舞い

- **まとめて設定、個別に直す**：全体の設定を全画像に当てる。個別に開いた画像で変えた設定は、その画像だけに効く。
- **容量の上限に合わせる**：JPEG は、上限以下に収まる最も高い画質を自動で選ぶ。長い辺の px を縮めても収まらない場合は、一覧で印を付ける。PNG は画質の段階がないため自動合わせの対象外とし、上限を超えたら印を付ける。
- **その場で確かめる**：一覧に変換後の容量と見本を出す。開いた画像で、元の画像と変換後の画像を拡大して見比べ、画質を手で動かせる。容量は設定・編集を変えるたびに更新する。
- **元を壊さない**：元のファイルは読むだけで、書き換えない。保存はすべてダウンロード（`src/lib/download.ts`）で、別のファイルとして作る。
- **付加情報**：書き出す画像には付加情報を一切残さない。写真の向き（Exif の回転指定）は、読み込み時に見た目どおりに直してから書き出す。
- **切り抜き・回転・塗りつぶし**：開いた画像の上で直接行う。塗りつぶした部分の元の画素は、書き出した画像に残さない。
- **書き込み**：開いた画像の上で直接描き、描いたあとも選んで動かす・大きさや色を変える・消すことができる。保存・コピー・PDF にまとめた画像に、画面で見たとおりに残る。編集（書き込み・切り抜き・回転）は画像ごとに取り消し・やり直しできる。
- **コピー**：保存する画像と同じ大きさ・編集の画像を、クリップボードに入れる。
- **画像 → PDF**：一覧の画像を、全体・個別の設定で縮めたもので、1枚1ページの PDF にする。ページの大きさは画像ごとにそのまま（余白なし）。PDF 全体の容量を表示する。
- **PDF → 画像**：PDF の各ページを JPEG・PNG にする。フォントを含まない PDF でも、日本語の文字が欠けないようにする。
- **開けない形式**：HEIC など、ブラウザーが開けないファイルは「この形式は開けません」と案内し、ほかのファイルの作業は続けられる。
- **画面を離れるとき**：未保存の作業があるうちに画面を離れようとしたら、確認を出す。作業内容はブラウザー内に残さない。

## 完了条件

1. 写真とスクリーンショットを十数枚まとめて読み込み、全体の設定を一度指定すると、一覧に各画像の変換後の容量と見本が出る。JPEG は上限以下で最も高い画質になり、収まらない画像には印が付く。
2. 開いた画像で元と拡大して見比べ、画質を手で変えられる。切り抜き・回転・塗りつぶしができ、塗りつぶした部分の元の画素は書き出した画像に残らない。
3. 「すべて保存」で各画像が別々にダウンロードされ、元のファイルは変わらない。位置情報を含む Exif 付きの写真から書き出した画像に、Exif が残らず、向きが正しい。
4. 画像をまとめた PDF、PDF のページの画像が作れる。フォントを含まない日本語の PDF でも、文字が欠けずに画像になる。
5. （2026-10-18 に PDF編集へ移した。重い PDF を小さくすること）
6. 矢印・枠・文字（日本語の入力を含む）・番号・蛍光ペンを書き込め、動かす・大きさや色を変える・消す・取り消す・やり直すができる。保存・コピーした画像に、画面で見たとおりに残る。
7. `node scripts/toolbox.mjs check` が通り、`src/tools/index.ts` と直下の README に登録されている。ネットにつながない状態で、`file://` から Windows の Edge と Mac の Chrome で動く。

## 実装で決めたこと

以前の未決事項と、実装時に委ねられたことの決め方。

- **PDF → 画像**：案のとおり、各ページを画像として一覧に並べ、全体の設定・個別の画面で写真と同じに扱う。ページは 200 dpi 相当で描画し（1ページ 1,600 万画素まで）、長い辺の設定でそこから縮める。
- **重い PDF を小さくするときに指定するもの**：容量の上限ではなく、画像の解像度と JPEG の画質を3段階（きれいめ 200 dpi・画質 85、標準 150 dpi・画質 75、小さめ 100 dpi・画質 60）から選ぶ。ページ上の大きさに対してこの解像度より細かい画像だけを縮める。2026-10-18 に、この機能を PDF編集へ移した（指定するものは変えていない）。
- **画像 → PDF のページの順番**：一覧の順。初めは追加した順で、2026-10-18 から左の列のドラッグで並べ替えられる。1 px を 0.75 pt（96 dpi）としたページにする。
- **画面の配置**（2026-10-18 に見直し）：1つの画面に、左に画像の列（見本・容量・印、並べ替え）、中央に開いた画像の編集、右に仕上がり（すべての画像の条件、この画像の容量の目盛り・大きさ・形式、この画像だけの設定、コピー・保存）を置く。加えた画像はすぐに中央に開く。以前は、カードの一覧と、画面いっぱいのダイアログの個別の画面（元と変換後を左右に並べ、「見比べる」「切り抜く」「塗りつぶす」を切り替える）に分けていた。一覧と個別の画面を行き来する手間と、書き込みのために道具を増やすと操作の切り替えが重なることから、PDF編集と同じ「左に列・中央に作業・右にパネル」の形にそろえた。
- **見比べ**（2026-10-18 に見直し）：一度は、左右に並べるのをやめ、保存する画像の上に元の画像（書き込み・切り抜き・回転を同じに当てたもの）を重ねて境目で切り分ける形にした。同日、ユーザーの求める見比べ（元の画像と編集した画像の新旧の比較）と合わないため、表示を左右に分けて左に元の画像（編集の前のまま）、右に保存する画像を並べる形に戻した。境目は置かない。拡大したときは左右で同じ場所を見せる。
- **全体の設定の既定値**：形式は自動（2026-10-18 から。以前は JPEG）、上限 1 MB、長い辺 1920 px。上限・長い辺は空にすると「なし」「元のまま」。上限は 1 KB = 1,000 バイトで数える（添付先の数え方より小さめになる）。設定は保存せず、開くたびに既定値に戻る。
- **JPEG の画質の自動選択**：30〜90 の整数から、上限以下で最も高い画質を選ぶ。上限がなければ 90。30 でも収まらなければ 30 の結果に印を付ける。
- **形式の自動選択**：PNG と最高の画質（90）の JPEG を書き出して比べ、PNG が上限に収まり、JPEG の 1.5 倍以下なら PNG、それ以外は JPEG（上限に合わせて画質を選ぶ）にする。書き込みの文字や画面の文字が JPEG のにじみで読みにくくならないようにするため。画質を手で決めた画像は JPEG にする。
- **書き込み**（2026-10-18）：道具は選ぶ・切り抜く・矢印・四角で囲む・丸で囲む・文字・番号・蛍光ペン・黒で隠すの9つで、キー1つで切り替える。色は赤・黄・緑・青・黒・白、大きさは小・中・大。太さ・大きさは描いたときの画像の長い辺に対する割合にし、画像の解像度に関係なく同じくらいの見え方にする。矢印は根元が細く矢じりに返しのある形、枠・矢印・番号には控えめな影を付け、文字には縁取りを付けてどんな背景でも読めるようにする。番号は描いた順に振り、消すと詰める。文字と番号は回転しても立てたまま描く。蛍光ペンは色を掛け合わせ、下の文字が読めるようにする。重ねる順は黒塗り・蛍光ペン・ほかの書き込み（描いた順）。描いたあとは選ばれた状態になり、どの道具でも書き込みの上をドラッグすれば動かせる（中が塗られた蛍光ペン・黒塗りは「選ぶ」か同じ道具のときだけ）。取り消しは画像ごとに 100 回まで。
- **コピー**（2026-10-18）：Chrome・Edge がクリップボードに入れられる画像は PNG だけのため、JPEG で保存する画像も、同じ大きさ・編集の劣化のない PNG にしてコピーする。
- **回転・塗りつぶし・切り抜き**：回転は90度単位。塗りつぶしは黒の長方形で、何か所でも塗れる。切り抜きと塗りつぶしはドラッグで長方形を囲む。切り抜きの範囲には大きさと縦横比を添え、矢印キーで 1 px ずつ動かせ、Shift＋矢印キーで幅・高さを変えられる（Alt＋← は Windows のブラウザーで「戻る」に当たるため使わない）。2026-10-18 から、塗りつぶしは書き込みの一つ（黒で隠す）として選んで動かせ、切り抜きは四隅の丸で大きさを、内側のドラッグで位置を変えられる。切り抜く道具では画像の全体を出し、ほかの道具では切り抜いた範囲を大きく出す。
- **透過のある画像を JPEG にするときの背景色**：白。
- **ファイル名**：画像は「元の名前-変換.jpg/png」、PDF のページは「PDFの名前-p01.jpg/png」、まとめた PDF は「画像まとめ.pdf」（小さくした PDF の「元の名前-縮小.pdf」は PDF編集へ移した）。

## 実装時に委ねること

- 画面の配置、一覧と個別の画面の切り替え方、見比べの表示のしかた（並べる・切り替えるなど）。
- 全体の設定の既定値（出力形式・容量の上限・長い辺）。
- 回転の単位、塗りつぶしの形と色、切り抜きの操作のしかた。
- 透過のある画像を JPEG にするときの背景色。
- 書き出すファイルの名前の付け方。
