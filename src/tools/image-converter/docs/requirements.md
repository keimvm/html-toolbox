# 画像変換ツール（image-converter）

toolbox に加える HTML ツール。メールや社内システムに添付できるように、画像の大きさ・容量・形式を変える。仕上がりはその場で確かめる。画像と PDF の相互変換、重い PDF を小さくすることもできる。

## 目的・背景

- 画像の容量が大きくて、メールや社内システムに添付できないことがある。
- 扱う画像は、写真とスクリーンショットが多い。

## 実現したい状態

- 一度に数枚から十数枚の写真やスクリーンショットをまとめて扱える。
- 「容量の上限に収まっていること」と「見た目が十分であること」の二つで、添付してよいかを判断できる。
- 変換結果の容量と画質を、その場で確かめながら決められる。容量と見た目のどちらを優先するかは、あらかじめ決めない。

## 扱う範囲 / 今は扱わないこと

扱う

- 画像のリサイズ・圧縮・形式変換（出力は JPEG・PNG）
- PDF：画像をまとめて1つの PDF にする、PDF のページを画像（JPEG・PNG）にする、重い PDF を PDF のまま小さくする
- 写真の位置情報を消す（撮影日時などほかの付加情報も合わせて消す）
- 切り抜き・回転
- 画面の一部を塗りつぶして隠す

今は扱わない

- ファイル名の付け直し
- PDF の編集（ページの削除・並べ替えなど）。PDF編集ツールで行う。
- WebP・AVIF の出力（添付先で開けない場合があるため）
- HEIC（iPhone の写真）の読み込み（必須ではなく、専用ライブラリの大きさとライセンスの負担が重いため）
- 作業状態を残して、画面を閉じた後に続きから再開すること

## 大切にしたいこと・制約

- 迷ったときの軸：手軽さ、仕上がりをその場で確かめられること、元の画像を壊さないこと。
- toolbox 全体の約束を守る：インストール不要、ネットにつながらない状態でも動く、`file://` で開いて使える、Windows と Mac の Chrome・Edge で動く、画像を外部へ送らない。

## 完了条件（推定）

- 数枚から十数枚の写真・スクリーンショットを選び、容量と見た目を確かめながら、添付先の上限に収まるファイルとして保存できる。元のファイルはそのまま残る。

- 大切にしたい三つ（手軽さ、仕上がりを確かめられること、元の画像を壊さないこと）がぶつかったときの優先順位（未確認）
