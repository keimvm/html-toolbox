# 単一HTMLで使うPDF編集・変換ツール

会社のPCでインストールせず、PDFを外部に送らずに、ページ編集・要素の確認と整理・形式変換ができるツールを作成する。

## 目的・背景

- Adobe系の製品を購入せずに、必要なPDF編集を行いたい。
- HTMLファイルを配るだけで、ほかの人も利用できるようにしたい。

## 実現したい状態

- PDFのページを整理し、中身の構成を確認して、不要な要素を削除できる。
- 必要な文字・画像を取り出したり、PDFを別のファイル形式に変換したりして再利用できる。

## 扱う範囲 / 今は扱わないこと

**扱うもの**

- Word・Excelなどから出力したPDFと、紙をスキャンしたPDF。
- ページの削除・並べ替え・結合・回転。
- 文字・画像・図形などをレイヤーのように見渡せる要素一覧、不要な要素の削除、文字・画像の取り出し。
- ページのPNG・JPEG保存と、PDFに含まれる文字情報を利用したテキスト・Markdown保存。

**今は扱わないもの**

- OCRは初版では後回しにする。文字情報のないスキャンPDFを文字として読み取る処理も含む。

## 大切にしたいこと・制約

- 単一HTMLを配布し、会社のPCでインストールせずに利用できること。
- PDFファイルやその内容を外部に送信しないこと。完全オフラインでの利用が必須かは未確認。
- Mac・Windowsの両方で、Edge・Chromeを対象とする。
- 初版の範囲を広げすぎず、OCRよりも合意した編集・取り出し・変換機能を優先する。

## 完了条件（ザックリ）

- 対象環境でHTMLを開き、PDFを外部に送らず、初版のページ操作・要素操作・形式変換を行える。（推定）
- 編集結果をPDFとして保存できる。（推定）
- 要素一覧・削除・取り出しと、Markdown変換の対応範囲が明示されている。（推定）

## 成果物の形式

- 配布してブラウザーで開ける、単一のHTMLファイル。
