# プロンプト集 要件

元の企画書：[requirements.md](requirements.md)。技術構成は [software-stack.md](software-stack.md) を参照。

## 目的

- AI チャットでよく使うプロンプトを、毎回探したり打ち直したりする手間をなくす。

## 利用者

- 本人。toolbox の一ツールとして zip に入れるため同僚の入口ページにも並ぶが、プロンプトは各自が選んだフォルダに分かれ、共有しない。
- 現時点のプロンプトは5件ほど。

## 主要な利用の流れ

1. 初回：保存先のフォルダを選ぶ → フォルダに保存ファイルがなければ新しく作り、あれば読み込んで一覧を出す。
2. 2回目以降：「前回のフォルダ（名前）を開く」を押し、ブラウザーが求めればアクセスを許可する → 一覧が出る。
3. タグを選んで絞り込み、目的のプロンプトの「コピー」を押す → AI チャットに貼る。一部を書き換えるプロンプトは、貼った後にチャット側で書き換える。
4. 必要に応じて、画面でプロンプトを追加・編集・削除する → 確定した時点でファイルに書き込まれる。

## 扱う範囲 / 今は扱わないこと

扱う

- プロンプトの追加・編集・削除（ツールの画面で）
- タグ付けと、複数タグでの絞り込み
- ボタンひとつでのコピー
- 保存先フォルダの選択・記憶と、PC のファイルへの保存

今は扱わない

- 毎回変わる部分をツール上で埋めてからコピーする機能
- 同僚とのプロンプトの共有
- ツールを通さずに保存ファイルを直接直す使い方

## 必要な機能と主要な振る舞い

- **プロンプトの項目**：タイトル・本文・タグ（0個以上。なしでも保存できる）。一覧ではタイトルで見分ける。
- **コピー**：各プロンプトの「コピー」ボタンで本文をクリップボードへコピーする。
- **追加・編集**：編集画面で「保存」を押したとき、すぐファイルへ書き込む。
- **削除**：実行前に確認を出し、確認して実行したとき、すぐファイルへ書き込む。
- **画面全体の保存ボタンは置かない**。未保存の変更を画面に溜めない。
- **タグでの絞り込み**：使われているタグを並べ、複数選べる。選んだタグをすべて含むプロンプトだけを出す（AND。選ぶほど減る）。選択を解除すると全件に戻る。
- **保存ファイル**：全プロンプトを選んだフォルダ内の1つのファイル（JSON）にまとめる。フォルダに無ければ新しく作る。
- **保存先の記憶**：選んだフォルダを覚え、2回目以降はボタンひとつ（と、ブラウザーが求める場合の許可）で開く。toolbox の新しい版に切り替えても同じフォルダを覚えていることを目指す（[software-stack.md](software-stack.md#未検証事項) の未検証を参照）。
- **保存先の変更**：用意するが、目立たない場所に置く。

## 完了条件

1. 初回にフォルダを選ぶと保存ファイルが作られ、タイトル・本文・タグを入れて追加したプロンプトがファイルに書き込まれる。
2. 編集の保存、確認を経た削除が、その時点でファイルに反映される。ツールを開き直しても内容が残っている。
3. 複数のタグを選ぶと、すべてを含むプロンプトだけが一覧に出る。
4. 「コピー」で本文がクリップボードに入り、AI チャットに貼れる。
5. 開き直したとき、前回のフォルダを選び直さずに一覧を出せる。
6. `node scripts/toolbox.mjs check prompt-library` が通り、`tools.json` と直下の README に登録されている。ネットにつながない状態で、`file://` から Windows の Edge と Mac の Chrome で 1〜5 が動く。

## 制約

- プロンプトはブラウザーの中ではなく、本人が選んだフォルダのファイルに残す。ブラウザー内にはフォルダの記録だけを置き、プロンプトの本文は入れない。
- toolbox 共通の約束：インストール不要、オフライン・`file://` で動く、Windows と Mac の Chrome・Edge 129 以降で動く、CDN・外部サイトを読み込まない、プロンプトを外部へ送らない。
- toolbox の[ツール追加の手順](../../../docs/development.md#ツールを追加する)と共通 UI（`ui/`）に従う。

## 実装時に委ねること

- 画面の配置、一覧の並び順、編集画面の形（`dialog` か画面内か）。
- タグの入力方法（既存タグの候補表示など）と、使われているタグの並び順。
- 保存ファイルの名前（英数字）と JSON の中身の形。後から形を変えられるよう、形式の版を持たせるかどうかも含む。
- コピーした後の知らせ方、非対応環境・許可拒否・読み書き失敗の案内の文言と表示。
