# プロンプト集（prompt-library）

toolbox に加える HTML ツール。AI チャットでよく使うプロンプトをためておき、タグで絞り込んで「コピー」ボタンですぐコピーできるようにする。

## 目的・背景

- AI チャットでよく使うプロンプトを、毎回探したり打ち直したりする手間をなくしたい。
- 使うのは本人だけ。同僚との共有は考えない。
- 現時点でよく使うプロンプトは5件ほど。

## 実現したい状態

- プロンプトにタグを付けておき、タグで絞り込んで目的のプロンプトを見つけられる。
- プロンプトごとの「コピー」ボタンを押すと、すぐにコピーでき、AI チャットに貼れる。
- ツールの画面で、プロンプトの追加・編集・削除ができる。
- プロンプトは PC のファイルとして残る。保存先のフォルダは本人が選ぶ。一度決めたら、基本的には変えない想定。
- 使い方は二通りある：そのまま貼るプロンプトと、貼った後に一部（例：「〇〇について要約して」の〇〇）をチャット側で書き換えるプロンプト。

## 扱う範囲 / 今は扱わないこと

扱う

- プロンプトの追加・編集・削除（ツールの画面で）
- タグ付けと、タグでの絞り込み
- ボタンひとつでのコピー
- 保存先フォルダの選択と、PC のファイルへの保存
- toolbox の zip に入れて配る（同僚の入口ページにも並ぶが、プロンプトは各自が選んだフォルダに分かれる）

今は扱わない

- 毎回変わる部分をツール上で埋めてからコピーする機能（一旦見送り。貼った後にチャット側で書き換える）
- 同僚との共有

## 大切にしたいこと・制約

- プロンプトはブラウザーの中ではなく、PC のファイルとして残す（開くだけで使える手軽さより、ファイルとして手元に残ることを選んだ）。
- toolbox 全体の約束を守る：インストール不要、ネットにつながらない状態でも動く、`file://` で開いて使える、Windows と Mac の Chrome・Edge で動く。
