# プロンプト集

AI チャットでよく使うプロンプトをためておき、タグで絞り込んで「コピー」ですぐ貼れるようにするツールです。toolbox に含まれる単一 HTML のツールで、プロンプトは自分で選んだ PC のフォルダにファイルとして保存し、外部へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../README.md#使い始める)）、一覧から「プロンプト集」を選びます。
2. 初回は「保存先のフォルダを選ぶ」を押し、プロンプトを保存するフォルダを選びます。ブラウザーが編集の許可を求めたら許可します。フォルダに `prompt-library.json` がなければ作り、あれば読み込みます。
3. 右上の「新しいプロンプト」で、タイトル・本文・タグを入れて「保存」します。タグは空白・カンマ・読点で区切ります。なくても保存できます。
4. 使うときは、上の「タグで絞り込む」からタグを選び、目的のプロンプトの「コピー」を押して AI チャットに貼ります。
5. 直すときは「編集」を押します。削除は編集画面の「削除…」から、確認のうえで行います。

### 保存のしかた

- 編集画面の「保存」、削除の確認の「削除」を押した時点で、`prompt-library.json` に書き込みます。画面全体の保存ボタンはなく、保存していない変更が画面に残ることはありません。
- 書き込む直前にファイルを読み直し、その内容に変更を加えて書き込みます。同じフォルダを別のタブでも開いている場合、ほかのタブで加えた変更を消しません。タブに戻ったときも、ファイルの内容で一覧を更新します。
- `prompt-library.json` が壊れている・形式が違うなどで読めない場合は、ファイルを上書きせず理由を表示します。直したあとに「もう一度読み込む」を押すか、別のフォルダを選んでください。
- ファイルは直接書き換えず、このツールの画面から編集してください。

### 次回から

選んだフォルダはブラウザーが覚えます。次に開いたとき、許可が残っていればそのまま一覧が出ます。出ない場合は「前回のフォルダ（名前）を開く」を押し、ブラウザーが求めればアクセスを許可します。

保存先を変えるときは、右上の「⋯」（保存先）から「保存先を変える…」を選びます。前のフォルダの `prompt-library.json` はそのまま残ります。

### 絞り込み

- 使っているタグが名前順に並びます。複数選ぶと、選んだタグを**すべて**含むプロンプトだけが出ます。選ぶほど件数が減ります。
- 「選択を解除」で全件に戻ります。一覧はタイトル順です。

### 一部を書き換えるプロンプト

「〇〇について要約して」のように毎回変わる部分があるプロンプトは、そのまま保存し、貼った後に AI チャット側で書き換えます。本文に `〇〇` などの目印を入れておくと探しやすくなります。

### 使えない・うまく動かないとき

- 「このブラウザーでは保存先のフォルダを使えません」と出る場合は、Chrome または Edge（129 以降）で開いてください。
- 「コピーできませんでした」と出る場合は、「編集」で本文を開き、選択してコピーしてください。
- 会社の管理設定でフォルダの読み書き（File System Access API）が止められている場合は使えません。

## 開発する

`tools/prompt-library/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm dev` で開発サーバー（<http://127.0.0.1:5175/>）が開きます。`pnpm build` は型検査のあと `dist/プロンプト集.html` を1ファイルで作ります。Node.js・pnpm の版、`test`・`test:dist`・`check` などのスクリプトの役割、リポジトリ直下からのテスト・検証は [共通の開発・リリース手順](../../docs/development.md#コマンド) に従います。

### ファイル配置

| 場所                                         | 内容                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `src/library.ts`                             | 保存ファイルの形（検査・書き出し）、タグの入力の区切り、AND の絞り込み、並び順、追加・編集・削除 |
| `src/storage.ts`                             | File System Access API での保存ファイルの作成・読み込み・書き込み（書き込み直前の読み直し）      |
| `src/folder-memory.ts`                       | 保存先のフォルダの記録（`ui/idb-record.js` で IndexedDB に固定のキーで保存）                     |
| `src/file-system-access.d.ts`                | TypeScript の DOM 型にない File System Access API の宣言                                         |
| `src/main.ts`・`src/style.css`・`index.html` | 画面                                                                                             |

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
