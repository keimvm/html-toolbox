# 画像変換

写真やスクリーンショットの大きさ・容量・形式を変えて、メールや社内システムに添付できるファイルにするツールです。仕上がりの容量と見た目をその場で確かめながら保存できます。画像をまとめて PDF にすること、PDF のページを画像にすること、重い PDF を PDF のまま小さくすることもできます。toolbox に含まれる単一 HTML のツールで、画像と PDF をこの PC の外へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../README.md#使い始める)）、一覧から「画像変換」を選びます。
2. 「画像・PDFを選ぶ」で写真やスクリーンショットをまとめて選ぶか、画面にドロップします。一覧に並びます。
3. 上の「全体の設定」で、出力形式（JPEG・PNG）、1枚あたりの上限、長い辺の px を決めます。全部の画像に当たり、一覧に変換後の大きさ・容量と見本が出ます。上限に収まらない画像には「上限を超えています」の印が付きます。
4. 気になる画像は「確かめる・直す」（または見本）を押して開きます。元の画像と変換後を並べて、全体・100%・200% で見比べられます。この画像だけ形式・長い辺・画質を変えたり、回転・切り抜き・塗りつぶしをしたりできます。
5. 「この画像を保存」か、一覧の「保存」「すべて保存」でダウンロードします。

最初の設定は JPEG・上限 1 MB・長い辺 1920 px です。上限を空にすると上限なし、長い辺を空にすると元の大きさのままになります。開いたときは毎回この設定に戻ります。

### 容量と画質

- JPEG は、上限に収まる最も高い画質を 30〜90 の中から自動で選びます。上限がないときは画質 90 です。
- 画質 30 でも収まらない画像には印が付きます。長い辺を小さくするか、個別の画面で長い辺や画質を下げてください。
- PNG は画質の段階がないため、自動では合わせません。上限を超えたら印が付きます。容量を減らすには長い辺を小さくするか、JPEG にします。
- 上限・容量は 1 KB = 1,000 バイト、1 MB = 1,000,000 バイトで数えます。添付先が 1,024 バイト単位で数えていても、収まる側にずれます。
- 画像は拡大しません。長い辺が設定より小さい画像は、元の大きさのままです。

### 個別の画面

- **見比べる**：左が元の画像（回転・切り抜き・塗りつぶしを当てたもの）、右が保存する画像です。どちらも変換後の画素数を基準に同じ大きさで並べます。100%・200% では、片方をスクロールするともう片方も同じ場所を表示します。
- **切り抜く**：画像の上をドラッグして、残す範囲を囲みます。囲み直すと範囲が変わります。「切り抜きをやめる」で元に戻ります。
- **塗りつぶす**：ドラッグで囲んだ範囲を黒く塗りつぶします。何か所でも塗れます。「塗りつぶしを1つ戻す」で最後に塗った範囲を消します。保存する画像には、塗りつぶした部分の元の画素は残りません。
- 「左に回す」「右に回す」で90度ずつ回します。
- 形式・長い辺・画質を変えると、この画像だけに効きます。「全体の設定に戻す」で個別の設定を消します（回転・切り抜き・塗りつぶしはそのまま）。画質のつまみを動かすには、「上限に合わせて自動で決める」を外します。
- 「前の画像」「次の画像」で、開いたまま隣の画像に移れます。

### PDF

- **PDF のページを画像にする**：「画像・PDFを選ぶ」で PDF を選ぶか、ドロップします。各ページを 200 dpi 相当の画像にして一覧に並べます（「報告書-p01」のような名前）。あとは写真と同じく全体の設定・個別の画面で扱い、保存します。フォントを含まない日本語の PDF でも、内蔵の日本語フォント（Noto Sans JP）で文字を描きます。
- **画像をまとめて PDF にする**：「PDFにまとめる」で、一覧の画像を今の設定で変換したものを、一覧の順に1枚1ページで並べた PDF を作ります。ページは画像と同じ縦横比で余白はなく、1 px を 0.75 pt（96 dpi）とします。できた PDF の容量を確かめてから「保存」します。
- **PDF を小さくする**：右上の「PDFを小さくする」で PDF を選び（ドロップも可）、仕上がりを選んで「小さくする」を押します。PDF の中の写真・スキャン画像だけを、指定の解像度（dpi）まで縮めて JPEG にし直します。文字・図形はそのまま残り、選択・検索もできます。変換前後の容量を確かめてから「保存」します。
  - 透過のある画像、白黒2値の画像、回転・反転して置かれた画像、グループ（Form XObject）の中の画像、JPEG にしても1割以上小さくならない画像は、元のまま残します。
  - ページの内容を作り直すため、PDF の作りによっては、しおり・フォーム・電子署名などが元の PDF と同じに残らない場合があります。保存した PDF を開いて確かめてください。
  - パスワードが必要な PDF は扱えません。

### 保存と付加情報

- 保存はすべてダウンロードです。元のファイルは変更しません。画像は「元の名前-変換.jpg」、PDF のページは「PDFの名前-p01.jpg」、まとめた PDF は「画像まとめ.pdf」、小さくした PDF は「元の名前-縮小.pdf」の名前で保存します。同じ名前のファイルがあると、ブラウザーが名前に番号を付けます。
- 「すべて保存」では、ブラウザーが複数のファイルのダウンロードを許可するか確かめることがあります。許可してください。
- 書き出す画像には、位置情報・撮影日時・カメラ情報などの付加情報（Exif）を一切残しません。写真の向きは、読み込むときに見た目どおりに直してから書き出します。
- 作業内容はブラウザー内に残しません。保存していない変換結果があるうちに画面を離れようとすると、確認が出ます。

### 開けないファイル

HEIC（iPhone の写真）など、ブラウザーが開けない形式は「この形式は開けません」と一覧に出ます。ほかの画像の作業はそのまま続けられます。HEIC は JPEG に書き出してから選んでください。

## 開発する

`tools/image-converter/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm dev` で開発サーバー（<http://127.0.0.1:5177/>）が開きます。`pnpm build` は型検査のあと `dist/画像変換.html` を1ファイルで作ります。Node.js・pnpm の版、`test`・`test:dist`・`check` などのスクリプトの役割、リポジトリ直下からのテスト・検証は [共通の開発・リリース手順](../../docs/development.md#コマンド) に従います。

### ファイル配置

| 場所                                         | 内容                                                                                               |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `src/settings.ts`                            | 全体・個別の設定、上限と長い辺の読み取り、容量の表示、ファイル名                                   |
| `src/fit.ts`                                 | 上限に収まる最も高い JPEG の画質を二分探索で選ぶ                                                   |
| `src/geometry.ts`                            | 回転・切り抜き・塗りつぶしの座標（元の画像の座標と、回した画像の座標の行き来）、縮めた大きさ       |
| `src/convert.ts`                             | Canvas での描画（塗りつぶし → 切り抜き → 回転 → 縮小）と JPEG・PNG の書き出し、一覧の見本          |
| `src/items.ts`                               | 一覧の画像と、1枚ずつ変換し直す順番待ち                                                            |
| `src/detail.ts`                              | 個別の画面（見比べ、切り抜き・塗りつぶしの操作、個別の設定）                                       |
| `src/main.ts`・`src/style.css`・`index.html` | 一覧・全体の設定・PDF のダイアログ・ドロップの受け付け                                             |
| `src/pdf/`                                   | PDFium の Worker（PDF → 画像、画像 → PDF、PDF を小さくする）。`runtime.ts` が PDFium の API を呼ぶ |
| `tests/samples.ts`                           | テスト用の合成データ（JPEG・PNG・写真入りの PDF）                                                  |

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
