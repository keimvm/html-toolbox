# タイピングゲーム 要件

元の企画書：[requirements.md](requirements.md)。技術構成は [software-stack.md](software-stack.md) を参照。

## 目的

- 好きなときに、練習問題を前もって用意せず、手元の文章を貼り付けてすぐタイピング練習をする。

## 利用者

- 本人と同僚。toolbox の一ツールとして `tools.json` と直下の README に登録し、zip に入れて配る。

## 主要な利用の流れ

1. ツールを開き、練習したい文章を貼り付ける。
2. 開始ボタンを押す → 3秒のカウントダウン → タイマーが動き出す。
3. 画面左の見本を見ながら、右の入力欄に日本語入力（IME）で打つ。途中で判定によって止められることはない。
4. 打ち終えたら、確定した後に Esc キーを押す → タイマーが止まり、結果が出る。
5. 結果（かかった時間と、見本と違う箇所）を見る → 「もう一度（同じ文章）」か「別の文章を貼る」で次へ進む。

## 扱う範囲 / 今は扱わないこと

扱う

- 文章の貼り付け、開始とカウントダウン、時間の計測
- 打っている間の進み具合の表示と経過時間の表示
- 打ち終えた後の、見本との差分による判定と結果の表示
- 同じ文章でのやり直しと、別の文章への切り替え

今は扱わない

- 1分あたりの文字数のような速さの目安
- 結果の記録・前回との比較、貼った文章の保存
- 英語など日本語以外の文章への配慮、ローマ字で読みを打つ形の練習
- 変換前の読みの打ち間違い、改行・空白、全角・半角の打ち分けの判定
- 画面上の終了ボタン

## 必要な機能と主要な振る舞い

- **画面**：左に見本（貼り付けた文章）、右に入力欄を並べる。
- **開始**：開始ボタンを押すと3秒のカウントダウンを出し、終わった時点からタイマーを動かす。
- **打っている間**
  - 左の見本は、確定した文字の数だけ先頭から色を変える。変換中でまだ確定していない文字は数えず、確定のたびにまとめて進む。改行・空白は数えない。
  - 見本と違う箇所は色で示さない。
  - 経過時間を、目立たない位置に小さく出す。
  - 画面に「確定後に Esc で終了」の案内を出す。
- **終了**：変換中の Esc キーは、普段どおり変換の取り消しになり、終了にはならない。確定した後の Esc キーでだけタイマーを止め、結果を出す。
- **判定**：打ち終えた後にまとめて行う。
  - 見本と入力の両方から改行・空白（全角・半角・タブ）を除く。
  - 全角・半角の違いをそろえてから（Unicode 正規化 NFKC）、文字単位で差分を取る。
  - 文字の抜けや余分な入力があっても、ずれを吸収し、違う箇所だけを違いとする。
- **結果**：かかった時間と、右の入力側に違う箇所を出す。
  - 余分に打った文字・打ち間違えた文字は、赤く示す。
  - 抜けた文字・本来打つべきだった文字は、打った文字と見た目で区別できる形で差し込む。
  - 文字は打ったまま（正規化前）で表示する。
- **次へ**：結果画面に「もう一度（同じ文章）」と「別の文章を貼る」を置く。前回の結果は残さない。

## 完了条件

1. 文章を貼って開始すると、3秒のカウントダウンのあとタイマーが動き、経過時間が出る。
2. IME で打つと、確定のたびに左の見本の色が確定した文字数分だけ進む。変換中は進まない。
3. 変換中の Esc キーでは終了せず変換が取り消され、確定後の Esc キーで終了して結果が出る。
4. 見本「今日はいい天気」に対して「今日いい転気」と打つと、「は」の抜けと「天」→「転」の打ち間違いだけが右側に示され、「いい」「気」は違いにならない。
5. 改行・空白の有無、全角・半角の違い（例：「2026」と「２０２６」）は違いにならない。
6. 結果画面から、同じ文章でもう一度打つことと、別の文章を貼り直すことができる。
7. `node scripts/toolbox.mjs check typing-game` が通り、`tools.json` と直下の README に登録されている。ネットにつながない状態で、`file://` から Windows の Edge と Mac の Chrome で 1〜6 が動く。

## 制約

- 開いてすぐ打ち始められる手軽さと、打った文字が色を変えながら進んでいく気持ちよさを大切にする（企画書）。
- toolbox 共通の約束：インストール不要、オフライン・`file://` で動く、Windows と Mac の Chrome・Edge 129 以降で動く、CDN・外部サイトを読み込まない、貼った文章を外部へ送らない。
- toolbox の[ツール追加の手順](../../../docs/development.md#ツールを追加する)と共通 UI（`ui/`）に従う。

- 案：文章を貼っていない状態では開始できないようにする。→ 実装で採用した（改行・空白以外の文字がないと「開始」を押せない）。

## 実装時に委ねること

- 貼り付ける場所（左の欄に直接貼るかなど）、ボタン・案内・経過時間の位置、狭い画面での並べ方。
- 色・線の具体的な形（見本の進み具合の色、赤の示し方、本来の文字の差し込み方）。
- カウントダウンの見せ方と、カウントダウン中・後の入力欄のフォーカスや入力の受け付け。
- 経過時間・結果の時間の表示形式（桁や単位）。
- 何も打たずに Esc を押した場合など、端の場合の扱い。
- `tools.json` の説明文と README の紹介文。
