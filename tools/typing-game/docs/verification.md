## 未確認のこと

- 実際の日本語入力での変換・確定・Esc の扱い（Windows の Edge と Microsoft IME、Mac の Chrome と日本語入力）。とくに、変換中に押した Esc が終了と取り違えられないこと、変換中に見本の色が進まないこと。
- 配布物を `file://` で開き、ネットにつながない状態で完了条件1〜6が動くこと（完了条件7）。内蔵のブラウザーでは `file://` のページを操作できなかった。
- 動きを減らす設定（`prefers-reduced-motion`）での表示。
