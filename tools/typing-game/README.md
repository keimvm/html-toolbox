# タイピングゲーム

手元にある好きな文章を貼り付けて、いつもの日本語入力（IME）で打つ練習をするツールです。打ち終えるまでの時間と、見本と違う箇所が分かります。toolbox に含まれる単一 HTML のツールで、貼った文章を保存せず、外部へ送信しません。

## 入手方法

toolbox のリリースに添付される `toolbox-<版>.zip` を解凍して使います。手順はリポジトリ直下の [README](../../README.md) を参照してください。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き、一覧から「タイピングゲーム」を選びます。
2. 左の「見本」の欄に、練習したい文章を貼り付けます。漢字まじりの文章のままで構いません。欄の外で貼り付けても、見本の欄に入ります。
3. 右の「開始」を押します（`Ctrl` + `Enter`、Mac は `⌘` + `Enter` でも開始できます）。3秒のカウントダウンのあと、右の「入力」の欄に打てるようになり、時間を測り始めます。
4. 左の見本を見ながら、いつもどおり変換して確定しながら打ちます。確定するたびに、打ったところまで見本の文字の色が先頭から変わっていきます。途中で止められることはありません。
5. 打ち終えたら、確定した後に `Esc` キーを押します。時間が止まり、結果が出ます。
6. 結果を見たら、「もう一度」で同じ文章をもう一度打つか、「別の文章を貼る」で見本を貼り替えます。

一覧へ戻るときは、画面左上の家のマーク（トップへ戻る）を押します。その右のボタンで明るい表示と暗い表示を切り替えられます（toolbox の全ツールで共通）。

### 打っている間

- 見本の色は、確定した文字で進みます（改行・空白は数えません）。余分に打った文字・抜かした文字があっても、見本と合っている所に位置を合わせ直します。打ち間違えた文字も色は進み、違いは打ち終えた後にまとめて示します。変換中でまだ確定していない文字は数えません。
- 次に打つ文字には、下に点滅する線が付きます。長い文章では、見本が打っている所に合わせてスクロールします。
- 右上に経過時間を小さく出します。見本の最後まで進むと、`Esc` の案内が光ります。
- 変換中の `Esc` は、いつもどおり変換の取り消しになり、終了にはなりません。カウントダウン中の `Esc` は、開始をやめて元の画面に戻ります。
- 1文字も確定せずに `Esc` を押したときは、結果を出さずに元の画面に戻ります。

### 結果の見方

- **かかった時間**：カウントダウンが終わってから `Esc` を押すまでの時間です。0.1秒の位まで出します。
- **見本との違い**：違う箇所の数です。続いている違いは1か所と数えます。違いがなければ「なし」と出ます。
- 右の欄に打った文章をそのまま並べ、違う箇所を示します。
  - 赤い文字（波線つき）：打ち間違えた文字・余分に打った文字
  - 淡い色の文字（破線の下線つき）：抜けた文字。打つべきだった見本の文字を差し込んで示します。途中で終えた場合、残りの文章も抜けとして最後に示します。
- 改行・空白の有無と、全角・半角の違い（例：「2026」と「２０２６」）は違いにしません。判定するのは確定した文字だけで、変換前の読みの打ち間違いは分かりません。
- 見本と大きく違い、判定に時間がかかりすぎる場合は、違う箇所を示さず、時間と打った文章だけを出します。

### 使えない・うまく動かないとき

- 「開始」を押せないときは、見本の欄に文章（改行・空白以外の文字）が入っているかを確認してください。
- 打っても文字が入らないときは、右の「入力」の欄をクリックしてから打ってください。

## 開発する

必要なものは Git、Node.js、pnpm です。

- Node.js：24.21.0 以降の24系を推奨。CI は [.node-version](.node-version) の24.21.0を使用します。26.9.0 以降の26系も許可しています。
- pnpm：12.4.2。[package.json](package.json) の `packageManager` で固定しています。

`tools/typing-game/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

| コマンド     | 内容                                                              |
| ------------ | ----------------------------------------------------------------- |
| `pnpm dev`   | 開発サーバー（http://127.0.0.1:5176/）                            |
| `pnpm build` | 型検査のあと、`dist/タイピングゲーム.html` を1ファイルで作る      |
| `pnpm test`  | ビルドし、Vitest で判定・見本の進み具合・時間の表示・配布物を検証 |
| `pnpm check` | 整形・lint・テスト・`git diff --check`                            |

リポジトリ直下からは `node scripts/toolbox.mjs check typing-game` で検証します。

### ファイル配置

| 場所                                         | 内容                                                                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `src/judge.ts`                               | 文字の数え方（改行・空白を除く）、打っている間の見本の位置、判定（空白の除去・NFKC・jsdiff の差分・元の文字への対応づけ） |
| `src/time.ts`                                | 経過時間・かかった時間の表示形式                                                                                          |
| `src/main.ts`・`src/style.css`・`index.html` | 画面（貼り付け・カウントダウン・打っている間の進み具合・結果）と動き                                                      |

要件は [docs/software-requirements.md](docs/software-requirements.md)、技術構成は [docs/software-stack.md](docs/software-stack.md)、検証結果は [docs/verification.md](docs/verification.md) を参照してください。
