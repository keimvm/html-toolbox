# 文字コード変換・確認ツール（mojicode-converter）

toolbox に加える HTML ツール。文字を入れるとその文字コードの値が分かり、コードの値を入れるとどの文字か分かる。

## 目的・背景

- ある文字の正体（文字コードの値や見た目）を確かめたい。
- 文字と文字コードの値を、どちら向きにも変換して確かめられるようにしたい。

## 実現したい状態

- 文字（1文字〜短い文章）を打つか貼り付けると、その文字コードの値が分かる。
- コードの値（例：`U+3042`、`82 A0`）を入れると、どの文字か分かる。
- 必ず分かること：コードの値
  - Unicode 系：Unicode の番号（U+3042 など）、UTF-8、UTF-16
  - Shift_JIS（Windows 版＝CP932。機種依存文字も含む）
- 見た目：大きく表示した形。PC（OS）に入っているフォントを選んで見え方を確かめられること

## 扱う範囲 / 今は扱わないこと

扱う

- 文字を入れてコードの値を見る
- コードの値を入れて文字を見る

今は扱わない

- プログラム・URL・HTML での表記の形
- 1文字ずつの一覧と文字の素性の表示
- テキストファイルを入れて、別の文字コードで読み直す・保存し直す
- EUC-JP、JIS（ISO-2022-JP）
- 文字の名前（例：HIRAGANA LETTER A）。データが大きくなるため後回し

## 大切にしたいこと・制約

- 迷ったときの軸：出てくる値が正しいこと（Windows やほかのツールで確かめた値と同じになること）を土台にする。
- toolbox 全体の約束を守る：インストール不要、ネットにつながらない状態でも動く、`file://` で開いて使える、Windows と Mac の Chrome・Edge で動く。
- フォントの選択は、できなければ無くてよい。
