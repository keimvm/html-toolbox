# 文字コード変換

文字を入れると文字コードの値が分かり、コードの値を入れるとどの文字か分かるツールです。toolbox に含まれる単一 HTML のツールで、入力した文字を外部へ送信しません。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../README.md#使い始める)）、一覧から「文字コード変換」を選びます。
2. 「文字」の欄に文字や短い文章を打つか貼り付けます。Unicode の番号・UTF-8・UTF-16・Shift_JIS の欄と、大きな表示がすぐ変わります。
3. コードの値から文字を調べるときは、どれかのコード欄を書き換えます（例：Shift_JIS の欄に `82 A0`）。文字とほかの欄が変わります。
4. 「大きく表示」で形を確かめます。フォントを変えるときは、フォント名を入力するか、「PCのフォントを一覧にする」を押して一覧から選びます。

入力した内容は保存しません。

### 各欄の書き方

欄ごとに文字コードが決まっています。入力の意味を推測しないため、値は対応する欄に入れてください。区切りは空白・カンマのどちらでも構いません。大文字・小文字は区別しません。

| 欄                          | 書き方の例                                                          | 表示        |
| --------------------------- | ------------------------------------------------------------------- | ----------- |
| Unicode の番号              | `U+3042`、`3042`、`0x3042`、`U+3042U+3044`                          | `U+3042`    |
| UTF-8（バイト）             | `E3 81 82`、`E38182`、`%E3%81%82`、`0xE3 0x81 0x82`、`\xE3\x81\x82` | `E3 81 82`  |
| UTF-16（符号単位）          | `D842 DFB7`、`D842DFB7`、`𠮷`                                       | `D842 DFB7` |
| Shift_JIS（Windows・CP932） | `82 A0`、`82A0`、`%82%A0`                                           | `82 A0`     |

欄から離れると、読めた値を表示の形にそろえます。読めない値を入れている間は、どこが読めないかを欄の下に示し、ほかの欄と大きな表示は前の値のまま薄く表示します。

### Shift_JIS の扱い

- Windows の Shift_JIS（CP932）として扱います。NEC特殊文字（①、㈱、Ⅰ など）、IBM拡張文字（髙、﨑 など）の機種依存文字もコードを出します。
- 同じ文字に二つ以上のコードがある場合（例：≒ は `81 E0` と `87 90`）、コードからはどれからも文字を引けます。文字からは Windows と同じ代表のコードを出します。
- Shift_JIS で表せない文字（𠮷、絵文字、`〜`（U+301C）、`¥`（U+00A5）など）は、Shift_JIS の欄を空にして「表せません」と示します。Windows の「似た文字への置き換え」（best fit）はしません。
- 外字（`F0 40`〜`F9 FC`）は、Windows と同じく私用領域の U+E000〜U+E757 として扱います。`80` は制御文字 U+0080 として読みます。`A0`・`FD`〜`FF` は文字になりません。

### フォントの一覧

「PCのフォントを一覧にする」は、ボタンを押したときにブラウザーの Local Font Access API を使います。通常、初回はブラウザーが許可を求めます。このツールが利用するのはフォントのファミリー名だけで、フォントの実データは取得せず、一覧を保存・外部送信しません。

フォント一覧は、一般には端末や所属組織の推測に使われることがある情報です。許可はブラウザーに残ることがあり、ブラウザーの権限設定から取り消せます（[Chrome の公式説明](https://developer.chrome.com/docs/capabilities/web-apis/local-fonts)）。

API は Windows・macOS のデスクトップ版 Chrome・Edge に対応しています。ただし、このツールの配布 HTML を `file://` で開いた場合の一覧取得と、Windows 実機での動作は未確認です。会社の管理設定でも利用を禁止できます（[Edge の管理ポリシー](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/DefaultLocalFontsSetting)）。許可しない場合や一覧が使えない場合も、フォント名を入力して切り替えられます。PC に入っていないフォント名を入れると、標準の書体で表示します。

## 開発する

`tools/mojicode-converter/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm dev` で開発サーバー（<http://127.0.0.1:5174/>）が開きます。`pnpm build` は型検査のあと `dist/文字コード変換.html` を1ファイルで作ります。Node.js・pnpm の版、`test`・`test:dist`・`check` などのスクリプトの役割、リポジトリ直下からのテスト・検証は [共通の開発・リリース手順](../../docs/development.md#コマンド) に従います。

### ファイル配置

| 場所                                         | 内容                                                                                                                    |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `src/sjis.ts`                                | Shift_JIS（CP932）の表。`TextDecoder('shift_jis')` で全コードを読み、逆引きと代表の選び方もここで決める                 |
| `src/codec.ts`                               | 各欄の読み取りと表示（U+番号・UTF-8・UTF-16・Shift_JIS）                                                                |
| `src/fonts.ts`                               | フォントの一覧（Local Font Access API）と `font-family` の値                                                            |
| `src/main.ts`・`src/style.css`・`index.html` | 画面                                                                                                                    |
| `tests/fixtures/`                            | テスト用の Microsoft の CP932 対応表（配布物に入れない）。入手元は [tests/fixtures/README.md](tests/fixtures/README.md) |
