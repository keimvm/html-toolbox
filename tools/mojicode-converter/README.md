# 文字コード変換

文字を入れると文字コードの値が分かり、コードの値を入れるとどの文字か分かるツールです。toolbox に含まれる単一 HTML のツールで、入力した文字を外部へ送信しません。

## 入手方法

toolbox のリリースに添付される `toolbox-<版>.zip` を解凍して使います。手順はリポジトリ直下の [README](../../README.md) を参照してください。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き、一覧から「文字コード変換」を選びます。
2. 「文字」の欄に文字や短い文章を打つか貼り付けます。Unicode の番号・UTF-8・UTF-16・Shift_JIS の欄と、下の一覧がすぐ変わります。
3. コードの値から文字を調べるときは、どれかのコード欄を書き換えます（例：Shift_JIS の欄に `82 A0`）。文字とほかの欄が変わります。
4. 「大きく表示」で形を確かめます。フォントを変えるときは、フォント名を入力するか、「PCのフォントを一覧にする」を押して一覧から選びます。

一覧へ戻るときは、画面左上の家のマーク（トップへ戻る）を押します。その右のボタンで明るい表示と暗い表示を切り替えられます（toolbox の全ツールで共通）。入力した内容は保存しません。

### 各欄の書き方

欄ごとに文字コードが決まっています。入力の意味を推測しないため、値は対応する欄に入れてください。区切りは空白・カンマのどちらでも構いません。大文字・小文字は区別しません。

| 欄                          | 書き方の例                                                          | 表示        |
| --------------------------- | ------------------------------------------------------------------- | ----------- |
| Unicode の番号              | `U+3042`、`3042`、`0x3042`、`U+3042U+3044`                          | `U+3042`    |
| UTF-8（バイト）             | `E3 81 82`、`E38182`、`%E3%81%82`、`0xE3 0x81 0x82`、`\xE3\x81\x82` | `E3 81 82`  |
| UTF-16（符号単位）          | `D842 DFB7`、`D842DFB7`、`𠮷`                                       | `D842 DFB7` |
| Shift_JIS（Windows・CP932） | `82 A0`、`82A0`、`%82%A0`                                           | `82 A0`     |

欄から離れると、読めた値を表示の形にそろえます。読めない値を入れている間は、どこが読めないかを欄の下に示し、ほかの欄と一覧は前の値のまま薄く表示します。

### Shift_JIS の扱い

- Windows の Shift_JIS（CP932）として扱います。NEC特殊文字（①、㈱、Ⅰ など）、IBM拡張文字（髙、﨑 など）の機種依存文字もコードを出します。
- 同じ文字に二つ以上のコードがある場合（例：≒ は `81 E0` と `87 90`）、コードからはどれからも文字を引けます。文字からは Windows と同じ代表のコードを出し、一覧に「ほかに 87 90」のように別のコードも示します。
- Shift_JIS で表せない文字（𠮷、絵文字、`〜`（U+301C）、`¥`（U+00A5）など）は、Shift_JIS の欄を空にして「表せません」と示します。Windows の「似た文字への置き換え」（best fit）はしません。
- 外字（`F0 40`〜`F9 FC`）は、Windows と同じく私用領域の U+E000〜U+E757 として扱います。`80` は制御文字 U+0080 として読みます。`A0`・`FD`〜`FF` は文字になりません。

### 一覧と表記の形

- 「1文字ずつの一覧」には、文字（コードポイント）ごとに各コードの値と素性（文字の種類、全角・半角、機種依存文字か、Shift_JIS で表せるか）を並べます。先頭1000文字まで表示します。
- 全角・半角は、Shift_JIS で表せる文字は1バイトなら半角、2バイトなら全角とします。表せない文字は Unicode の文字幅（East Asian Width の主な範囲）による目安です。
- 改行・空白・制御文字などの見えない文字は、一覧に名前で示します。結合文字は点線の丸（◌）に重ねて示します。
- 「表記の形」には、プログラム（`あ`・`\u{3042}`）、URL（UTF-8 の `%E3%81%82`、Shift_JIS の `%82%A0`）、HTML（`&#12354;`・`&#x3042;`）の書き方を出します。欄を押すと全体を選択するので、そのままコピーできます。

### フォントの一覧

「PCのフォントを一覧にする」は、ブラウザーの Local Font Access API を使います。初回はブラウザーが許可を求めます。許可しない場合や、一覧が使えない環境（会社の設定で止められている場合など）では、フォント名を入力して切り替えてください。PC に入っていないフォント名を入れると、標準の書体で表示します。

## 開発する

必要なものは Git、Node.js、pnpm です。

- Node.js：24.21.0 以降の24系を推奨。CI は [.node-version](.node-version) の24.21.0を使用します。26.9.0 以降の26系も許可しています。
- pnpm：12.4.2。[package.json](package.json) の `packageManager` で固定しています。

`tools/mojicode-converter/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

| コマンド     | 内容                                                       |
| ------------ | ---------------------------------------------------------- |
| `pnpm dev`   | 開発サーバー（http://127.0.0.1:5174/）                     |
| `pnpm build` | 型検査のあと、`dist/文字コード変換.html` を1ファイルで作る |
| `pnpm test`  | ビルドし、Vitest で変換・対応表・配布物を検証              |
| `pnpm check` | 整形・lint・テスト・`git diff --check`                     |

リポジトリ直下からは `node scripts/toolbox.mjs check mojicode-converter` で検証します。

### ファイル配置

| 場所                                         | 内容                                                                                                                    |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `src/sjis.ts`                                | Shift_JIS（CP932）の表。`TextDecoder('shift_jis')` で全コードを読み、逆引きと代表の選び方もここで決める                 |
| `src/codec.ts`                               | 各欄の読み取りと表示（U+番号・UTF-8・UTF-16・Shift_JIS）                                                                |
| `src/props.ts`                               | 文字の素性（種類・全角半角・機種依存文字）                                                                              |
| `src/notation.ts`                            | 表記の形                                                                                                                |
| `src/fonts.ts`                               | フォントの一覧（Local Font Access API）と `font-family` の値                                                            |
| `src/main.ts`・`src/style.css`・`index.html` | 画面                                                                                                                    |
| `tests/fixtures/`                            | テスト用の Microsoft の CP932 対応表（配布物に入れない）。入手元は [tests/fixtures/README.md](tests/fixtures/README.md) |
