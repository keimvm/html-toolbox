# ローカルノート

任意のローカルフォルダ内の Markdown を閲覧・編集するノートアプリです。toolbox に含まれる単一 HTML のツールです。CSS・JavaScript・Markdown パーサーとライセンスを内包しています。

## 使い方

1. toolbox の `index.html` を Chrome または Edge で開き（[使い始める](../../README.md#使い始める)）、一覧から「ローカルノート」を選びます。
2. ヘッダーのフォルダのアイコン（フォルダを開く）からノートのフォルダを選択します。
3. 左のツリーから `.md` / `.MD` を選びます。
4. 表示された本文を直接編集し、「保存」または `Cmd+S` / `Ctrl+S` で元ファイルに保存します。

**検証状況:** 自動テストではファイル API を模擬しています。実フォルダでの新規作成・名前変更・削除、ノート・添付の保存、`file://` での復元、完全オフライン、Windows・Edge、OS の日本語 IME、同期フォルダ、通常の印刷画面からの PDF 保存・キャンセルは未確認です。移行前の Chrome 検証と今回の確認結果は [検証記録](docs/VERIFICATION.md) に分けて記録しています。

## 操作と保存

- フォルダをクリックして展開・折りたたみします。フォルダ優先・名前順に並び、隠しフォルダも表示します。添付用のルート直下の`.assets`は表示しません。フォーカス中は上下キーで移動、左右キーで展開・折りたたみできます。
- 各行の「⋯」からファイル・フォルダの追加、名前変更、削除ができます。フォルダ行ではその直下、ファイル行では同じ親フォルダに追加します。新規ファイルはMarkdown（`.md`）になります。ルート行は追加のみです。
- 名前変更はコピー内容を確認してから元の項目を削除します。開いているノートの未保存本文・編集履歴は維持します。他のノートからのリンクは自動更新されません。失敗時にコピーが残る場合は通知します。
- 削除前に対象を確認します。フォルダ内はMarkdown以外も対象で、ゴミ箱には入りません。編集中のノートを含む場合は保存・破棄・キャンセルを選べます。同名項目は上書きせず、外部変更を検知した場合は操作を止めます。
- ナビゲーションと編集領域の境界をドラッグすると、左右の幅を調整できます。境界に Tab キーで移動すると、左右キーで10px、Shift＋左右キーで50px、Home / End で最小 / 最大幅に変更できます。ドラッグ中の Escape は調整を取り消します。
- 上部のファイル名の左のボタンでナビゲーションを開閉できます。閉じると編集領域が広がり、再表示時は前回の幅に戻ります。未保存本文や編集履歴は維持します。680px以下の画面では上下配置となり、開閉だけを利用できます。
- 見出し・太字・リスト・表などを表示したまま、本文に直接入力できます。上部の「書式」を開いて書式を選びます。「挿入・操作」から引用・コード・区切り線・表の挿入、表の行列の追加削除、取り消し・やり直しを行えます。
- 「その他の操作（⋯）」→「Markdownソース」で記法を直接編集し、「本文に戻る」で整形表示へ戻ります。切り替えでは保存せず、未保存内容を引き継ぎます。
- 画像・ファイルを整形された本文にドラッグ＆ドロップすると、その位置へ追加できます。「書式」→「挿入・操作」→「画像・ファイルを追加」でも選べます。複数選択に対応し、画像は本文に表示、それ以外はファイル名のリンクになります。
- ファイルは開いたフォルダ直下の`.assets`に、その場でコピーします。初回は必要に応じて「許可して追加」を選び、ブラウザーの書き込み許可を与えてください。元ファイルは移動・変換しません。同名でも別名で保存します。本文の参照は従来どおり「保存」で確定します。
- 追加した参照はまとめて取り消せます。Undo・本文の破棄・リンク削除でもコピーしたファイルは残ります。不要になったファイルは、他のノートからの参照がないことを確認してFinder等で整理してください。フォルダのドロップ、画像のクリップボード貼り付け、ソース画面でのファイル追加には対応しません。
- `Cmd/Ctrl+B` で太字、`Cmd/Ctrl+I` で斜体、`Cmd/Ctrl+K` でリンク、`Cmd/Ctrl+Z` で取り消し、`Cmd/Ctrl+Shift+Z` でやり直しができます。行頭の `# `、`- `、`1. `、`> ` も書式に変換します。
- 直接編集後は、リスト記号・空行・URLのエンコードなどの表記を整える場合があります。開いただけ、カーソル移動、ソースとの切り替えだけでは原文を変更しません。ソースでの変更は、本文を直接編集するまでその記法を保持します。
- ファイル・フォルダの切り替えや再読み込み時に未保存変更があれば、保存・破棄・キャンセルを選べます。保存や取得に失敗した場合は本文を保持します。
- ヘッダーの回転矢印のアイコン（再読み込み）はツリーと選択中の本文を読み直します。フォルダのアイコン（フォルダを開く）とともに、ナビゲーションを閉じている間も利用できます。どちらもポインターを重ねると操作名が表示されます。フォルダの常時監視は行いません。
- ページのリフレッシュや開き直しでは、前回のフォルダ・選択中のノート・ツリーの展開状態を復元します。読み取り権限が残っていれば自動で開き、再許可が必要な場合は前回のフォルダ名と「アクセスを許可して開く」を表示します。
- 本文は保存済みのファイルから読み直し、直接編集の表示で開きます。未保存の本文、編集履歴、カーソル・スクロール位置は復元しません。前回のノートが開けなくても、フォルダを表示できれば別のノートを選べます。
- 保存の直前に元ファイルの内容を比較します。外部変更や対象の削除・移動があれば上書きを止めます。競合時は本文をコピーしてから、必要に応じて編集を破棄し再読み込みしてください。
- UTF-8 の BOM 有無と LF / CRLF を維持します。非 UTF-8、改行混在、単独 CR、NUL を含むファイルは理由を表示し、閲覧のみに限定します。改行がまだないファイルで最初の改行を追加する場合は LF を使用します。
- トップへ戻る・タブを閉じる・ページを再読み込みする際は、未保存ならブラウザー標準の確認を要求します。自動保存や終了後の下書き復元はないため、残したい変更は先に「保存」してください。

同期フォルダはローカルに実体があるファイルを扱います。「保存済み」はローカルファイルへの書き込み完了を意味し、クラウドへの同期完了は判定しません。比較後から書き込み確定までの同時編集を完全に防ぐ排他制御はありません。

## 表示とエクスポート

チェック済みの項目は文字とリンクが薄いグレーになり、解除・Undo/Redoで戻ります。子タスクは自身のチェック状態で表示します。「その他の操作（⋯）」→「設定」の「本文フォントサイズ」で14・16・18・20・24pxを選べます。標準は16pxで、本文・Markdownソース・見出し・表・コードに反映し、次回にも引き継ぎます。本文や編集履歴は変更しません。

同じ設定画面の「UIフォント」では端末にあるフォント名を指定できます。候補から選ぶか名前を入力し、空欄で標準に戻します。本文の書体は変えず、ナビゲーション・ボタン・メニュー等へ反映し、次回にも引き継ぎます。

「その他の操作（⋯）」→「エクスポート」から、開いているノートの最新内容を出力できます。Markdownソースでの編集と未保存の変更も含み、元ファイルへの保存や未保存状態の解除は行いません。

- **HTMLをダウンロード**：本文のCSSとローカル画像を埋め込んだ単独のHTMLを保存します。元ノートの拡張子を`.html`に置き換えます。スクリプトを含まず、チェックボックスは閲覧専用です。
- **PDFに保存**：本文だけを印刷画面へ渡します。送信先で「PDFに保存」を選び、用紙・保存先を指定してください。本文の余白は各ページ16mmです。表示サイズやチェック済みの色も反映し、ブラウザが余白に付けるタイトル・日時・ファイルパス・ページ番号は出力しません。
- 添付ファイルや別ノートは表示名と参照先だけを残します。外部Webリンクと文書内の見出しリンクは利用できます。外部画像は取得せず、ローカル画像を取得・表示できない場合は本文と画面に案内します。
- ノート未選択・IME変換中・他の処理中は出力できません。出力準備中は編集やノートの切り替えを止め、失敗時は内容を保って再操作できます。

本文上部はトップへのリンク・ファイル名・書式・その他の操作・保存状態・保存をまとめ、狭い画面では折り返します。ファイルのフルパスはファイル名にポインターを重ねるか、「その他の操作（⋯）」で確認できます。書式は本文に重なるメニューで開き、メニューの外側のクリックやEscapeで閉じます。画面内の使い方と下部の情報欄は設けず、操作説明はこのREADMEにまとめています。依存ライブラリのバージョン・ライセンスは配布HTML内の非表示の`template#third-party-licenses`に保持します。

## Markdown と参照先

見出し、強調、取り消し線、リスト、引用、区切り線、コード、リンク、画像、表、タスクリストに対応します。タスクリストはクリックでチェック状態を編集できます。生の HTML は文字列として表示します。

チェックボックスを入れるには、本文の段落にカーソルを置き、ヘッダーの「書式」→「チェックボックス」を選びます。空の行から追加でき、既存の本文・箇条書き・番号付きリストも文字を残して変換できます。チェック項目ではメニューのボタンが選択状態になり、もう一度押すとチェックボックスを外します。

行頭に `- [ ] `（最後に半角スペース）を入力する方法でも、ToDo のチェックボックスを表示します。`- [x] ` / `- [X] ` は完了済みになります。既存の箇条書きや番号付きリストでも、項目の先頭に `[ ] ` を入力して変換できます。クリックでチェック状態を変更でき、Enter で次の未完了項目を作れます。文字が空の項目も保存できます。

空の段落に `---` を入力すると区切り線と次の本文行を作ります。段落の先頭でバッククォートを3個入力するとコードブロックへ変換し、バッククォート2個で文字を囲む（例：`` `code` ``）とインラインコードへ変換します。先にバッククォート2個を入力し、間へカーソルを移して文字を入れる操作にも対応します。変換直後のBackspaceで記号に戻せます。インラインコードの末尾で右矢印を押すと、続けて通常の本文を入力できます。

コードブロック内の Ctrl+A（Mac では Cmd+A も対応）は、そのブロックの中だけを選択します。コードブロックの末尾でEnterを2回、または次もコードブロックか後続の行がない位置で下矢印を押すと、通常の本文行を作れます。連続するコードブロックの間にも本文を入力できます。Shift+Enter / Cmd・Ctrl+Enterでもコードの後ろに本文行を作れます。

表は先頭行が見出しの Markdown 表を扱います。セル内は1段落で、Enter / Tab は次のセル、Shift+Tab は前のセルへ移動します。最後のセルで Enter / Tab を押すと次の行を追加します。セル結合・セル内の複数行やブロックには対応せず、対応できない表の貼り付けは案内して止めます。画像・添付の参照先は Markdownソースで変更できます。先頭の YAML / TOML フロントマターは原文ブロックとして保持し、ソースから編集できます。

- 本文のリンクは通常クリックで編集し、`Cmd/Ctrl+クリック`（キーボードではリンクにフォーカスして Enter）で開きます。相対 `.md` リンクは、リンク元のフォルダを基準にアプリ内で開きます。
- ルート内の PNG / JPEG / GIF / WebP は読み取り専用で表示します。
- `.assets`内の添付リンクは、`Cmd/Ctrl＋クリック`またはリンクにフォーカスしてEnterで開けます。PDF・テキスト・対応画像・音声・動画は別タブで開き、表示されない場合は通知の「ダウンロード」を使えます。HTML・SVG・その他の形式はダウンロードします。
- ノートには標準の画像・リンク記法と相対パスを保存します。サブフォルダのノートも、ルートの`.assets`を参照します。
- 外部の画像は自動取得せず、代替テキストとリンクを表示します。
- `http:` / `https:` のリンクは別タブに開きます。
- ルート外、絶対ローカルパス、その他の URL スキームは自動アクセスしません。

ブラウザ内の IndexedDB に、最後に開いたフォルダのハンドル、選択中ノートと展開中フォルダの相対パスを記録します。ナビゲーションの幅と開閉状態、表示設定はそれぞれ別の記録に保存し、フォルダ未選択・再許可待ちでも復元します。同じブラウザーのプロファイル・同じ HTML の配置場所が復元単位です。同じ場所を複数タブで開いた場合は、それぞれの最後に記録した状態が次回の復元に使われます。HTML の移動、別プロファイル、ブラウザの保存データ削除などで記録を利用できない場合は、フォルダを選び直してください。

レイアウトはドラッグ終了・キーボード調整・開閉時に記録します。画面縮小時は表示幅だけを制限し、画面を広げると希望した幅に戻します。記録が利用できなければ初期レイアウトで起動し、保存に失敗してもその場の操作は継続できます。

復元情報の記録はフォルダ・ノートの読み込み成功時と展開操作時に行います。ブラウザの強制終了直前など、記録の完了前に終了した操作は戻らない場合があります。保存領域が利用できなくても手動で開いて編集・保存できます。本文はブラウザに保存せず、OPFS、対象フォルダへの管理ファイル作成も使用しません。localStorage には toolbox 共通の表示（明るい・暗い）の選択だけを保存します。

新しい版へ切り替える前の注意は、直下の README の [データの扱い](../../README.md#データの扱い) を参照してください。

## 開発する

既存の esbuild と Node.js のテストランナーを使います。Node.js・pnpm の版は [.node-version](.node-version) と [package.json](package.json) で固定し、ほかのツールとは独立して管理します。ライブラリとロックファイルは移行前のものを維持しています。`test`・`test:dist`・`check` の役割と、リポジトリ直下からのテスト・検証・zip作成は [共通の開発・リリース手順](../../docs/development.md#コマンド) に従います。

`tools/note-html/` で実行します。開発サーバーはありません。

```sh
pnpm install --frozen-lockfile
pnpm build
```

`pnpm build` は `dist/` を作り直し、JS・CSS・ライセンスを内包した `dist/index.html` を生成します。編集対象は `src/` です。`src/index.html` はテンプレートなので直接開かず、生成した `dist/index.html` を Chrome または Edge で開きます。生成物は直接編集しません。`dist/` と検証記録の `output/` は Git 管理対象外です。

toolbox の戻るリンク・版番号を含めて確認するときは、リポジトリ直下のローカルビルド（`node scripts/toolbox.mjs build <版>`）で作った `out/toolbox-<版>/index.html` を開きます。共通処理が `dist/index.html` を `tools/note-html.html` として収集します。

自動テストはファイル API を模擬しており、実ノートを読み書きしません。実機では検証専用のフォルダを使い、通常の編集・保存、未保存時のトップへの移動とキャンセル、保存後の往復、狭い画面の折り返しを確認し、結果を [検証記録](docs/VERIFICATION.md) に残します。機能要件は [仕様書](docs/SPEC.md) を参照してください。
