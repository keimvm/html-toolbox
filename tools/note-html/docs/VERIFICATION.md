4. 確認用ノートを外部で変更・移動して更新し、最新の保存済み本文を読むこと、対象がなければツリーから別ノートを選べることを確認する。
5. 未保存の変更を加えてページを更新し、離脱確認が出ることを確認する。離脱した場合は保存済み本文に戻り、下書きを復元しないことを確認する。

以下は 2026-09-09 の直接編集対応時の記録です。Chrome の画面検証結果はその時点の配布物に対するもので、今回の復元 UI を確認済みとは扱いません。

## 実装

「閲覧」「編集」タブを廃止し、整形表示した Markdown を直接編集する本文と書式バーを追加しました。「Markdownソース」からソースを編集し、未保存内容を保持したまま本文へ戻れます。既存のフォルダツリーと本文デザインを引き継いでいます。

見出し・強調・取り消し線・リスト・チェック・引用・コード・リンク・区切り線・表に対応します。表はセルの編集と行列の追加削除ができ、セル結合やセル内の複数行は対象外です。画像は既存の参照先制限を保って表示し、追加・参照変更はソースで行います。先頭の YAML / TOML フロントマターは原文ブロックとして保持します。

表示だけでは原文を変更しません。文書を直接編集した後は意味と表示を保って記法を正規化します。ソースとの往復でエディタを作り直さず、取り消し・やり直しの履歴を保持します。外部変更検知、保存失敗時の本文保持、BOM と改行コードの維持も継続します。

配布物はリポジトリ直下の単一 `index.html` です。JavaScript、CSS、実際に同梱する22ライブラリの全文ライセンスを内包しています。実行時にサーバーやネットワーク接続は必要ありません。

主要な依存関係は `markdown-it` 14.2.0、`prosemirror-markdown` 1.13.7、`prosemirror-view` 1.42.3、`prosemirror-tables` 1.8.5（いずれも MIT）です。全バージョンは `pnpm-lock.yaml`、全文ライセンスは現在、配布HTML内の非表示テンプレートで保持しています。
