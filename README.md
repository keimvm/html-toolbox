# toolbox

toolbox は、PC の中で完結する便利ツール集です。受け取った zip を解凍し、`index.html` を Chrome または Edge で開くだけで使えます。アプリのインストールは不要で、ネットにつながっていなくても動きます。扱うファイルや入力した内容は外部へ送りません。

## 使い始める

1. 配布された `toolbox-<版>.zip` を PC に保存します。
2. zip を解凍します（zip の中から直接開かないでください）。
3. 解凍してできた `toolbox-<版>` フォルダの `index.html` を Chrome または Edge で開きます。
4. ホームのタイルから、使いたいツールを選びます。

全ツールが `index.html` の1ファイルに入っています。別の場所へ移すときも、このファイルだけを移せば動きます。

## 使えるツール

| ツール | できること |
| --- | --- |
| [プロンプト集](src/tools/prompt-library/README.md#使い方) | よく使う AI チャットのプロンプトを PC のフォルダに保存し、タグで絞り込んで、ボタンか数字キーでコピー |
| [画像変換](src/tools/image-converter/README.md#使い方) | 写真やスクリーンショットのリサイズ・圧縮・形式変換（JPEG・PNG）、容量の上限に合わせた画質の自動調整、切り抜き・回転・塗りつぶし、画像と PDF の相互変換、重い PDF の縮小 |
| [PDF編集](src/tools/pdf-edit/README.md#使い方) | PDF のページの削除・並べ替え・回転・結合、画像や文字の取り出し、ページの中の要素（画像・図形・文字）の削除 |
| [ローカルノート](src/tools/note-html/README.md#使い方) | PC のフォルダにある Markdown の閲覧・編集・保存、画像やファイルの添付、HTML・PDF への書き出し |
| [文字コード変換](src/tools/mojicode-converter/README.md#使い方) | 文字と文字コードの値（Unicode の番号・UTF-8・UTF-16・Shift_JIS）の相互変換、フォントを切り替えて文字の形を確認 |
| [タイピングゲーム](src/tools/typing-game/README.md#使い方) | 貼り付けた文章を見本にした日本語入力の練習、かかった時間と見本と違う箇所の確認 |
| [文章比較](src/tools/text-compare/README.md#使い方) | 2つの文章（契約書・手順書の新旧、AI が書き直した文章など）の違う箇所を色分けして表示 |

## ホームから始める

ホームには、ツールのタイルが並びます。タイルを押すとそのツールが開きます。

- **ファイル・フォルダを置く**：ホームにファイルやフォルダをドラッグすると、受け取れるツールのタイルが光ります。タイルの上に落とすとそのツールで開き、それ以外の場所に落とすと、使えるツールを選ぶ画面が出ます（使えるツールが1つならそのまま開きます）。
  - 画像 → 画像変換（2枚以上なら「まとめて1つのPDFにする」も選べます）
  - PDF → PDF編集・画像変換（ページを画像にする、小さくする）
  - フォルダ → ローカルノート・プロンプト集の保存先
  - テキストファイル → タイピングゲーム・文章比較（2つなら文章比較で比べます）
- **貼り付ける**：ホームで ⌘V（Windows は Ctrl+V）を押すと、コピーしている文章や画像を使えるツールで開きます。文章ならプロンプト集・文字コード変換・タイピングゲーム・文章比較から選べます。スクリーンショットなどの画像は画像変換に入ります。
- **並べ替え・表示**：タイルの並び順と、ホームに出すツールを変えられます。右上の「並べ替え・表示」を押し、タイルをドラッグするか「前へ」「後へ」で並べ替えます。使わないツールは「表示」のチェックを外します。選んだ内容はこの PC のブラウザーに残り、新しい版でも引き継がれます。

使っているツールのタイルには、開いているファイル名などの作業の様子が出ます。保存していない作業がある場合は、印が付きます。

## ツールの画面

各ツールの左上には、ホームへ戻るボタン（家のマーク）、ツールのアイコンと名前、表示の切り替えボタン（月・太陽のマーク）が並びます。

- **ほかのツールへ移る**：ツールの名前を押すと、全ツールの一覧が出ます。ツールを移っても、開いていたツールの作業内容はそのまま残ります（ページを閉じたり再読み込みしたりすると消えるものもあります。次の「データの扱い」を参照）。
- **ツールの間で受け渡す**：画像変換でまとめた PDF を「PDF編集で開く」、PDF編集で並べ直した PDF を「画像変換でページを画像にする」「画像変換で小さくする」のように、作業の続きを別のツールへ渡せます。
- **画面の色**：最初は PC のダークモードの設定に合わせます。切り替えボタンで明るい表示と暗い表示を選べ、ホームと全ツールで共通です。PC の設定と同じ表示に戻すと、以後は PC の設定に従います。印刷と、ローカルノートの書き出しは明るい表示で出力します。
- **背景の流れ**：ホームの背景には、マウスの動きに合わせて渦を巻く細い線が流れます。気になるときは版番号の右にある波のマークで止められます。PC で動きを減らす設定にしている場合は表示しません。

保存していない作業があるときにページを閉じようとすると、ブラウザーが確認を出します。

## データの扱い

どのツールも、扱うファイルや入力した内容をこの PC の中だけで処理し、外部へ送りません（通信そのものを止めています）。保存のしかたと、新しい版に切り替える前にすることはツールごとに次のとおりです。

- **プロンプト集**：プロンプトは、自分で選んだフォルダの `prompt-library.json` に、追加・編集・削除を確定した時点で書き込みます。ブラウザーの中には保存先のフォルダの記録だけを残し、新しい版でも同じフォルダを開きます。
- **画像変換**：元のファイルは変えず、変換した画像や PDF を「保存」で別のファイルとしてダウンロードします。作業内容はブラウザーに残さないため、ページを閉じると消えます。残したい画像は保存してください。
- **PDF編集**：元の PDF は変えず、編集結果を「保存」で別のファイルとしてダウンロードします。再読み込みやタブを閉じたときに続きから開けるよう、開いた PDF と編集の状態をブラウザーの中に残し、「閉じる」で消します。この記録は新しい版でも読めます。
- **ローカルノート**：選んだフォルダの Markdown を、「保存」（⌘S / Ctrl+S）で元のファイルに書き込みます。保存していない本文はブラウザーに残しません。前回のフォルダ・ノート・表示設定は、新しい版でも引き継ぎます。
- **文字コード変換**・**タイピングゲーム**・**文章比較**：入力した内容も結果も保存しません。ページを閉じると消えます。

この版で作りが新しくなったため、以前の版から切り替えたときに一度だけ、ローカルノートのフォルダを選び直す必要があります（ノートはフォルダに残っています）。PDF編集で作業中のものがあれば、切り替える前に保存してください。プロンプト集の保存先、ホームの並び順、画面の色は引き継がれます。

## 利用できる環境

- Windows または Mac
- Chrome または Edge 129 以降（最新の安定版を推奨。Safari は対象外）

フォルダを使うツール（プロンプト集・ローカルノート）は、最初にフォルダを選ぶときにブラウザーがアクセスの許可を求めます。会社の PC での動作は確認中です。

## 版の確認と更新

ホームの上部と各ツールの右下に、`2026.10.18` のような版番号が表示されます。同じ日に複数の版が出た場合は、`2026.10.18.2` のように末尾に番号が付きます。

新しい版を受け取ったら、作業結果をファイルに保存してから（[データの扱い](#データの扱い)）、新しい zip を解凍し、その中の `index.html` を開いてください。版ごとにフォルダが分かれるので、古い版に上書きする必要はありません。自動更新は行いません。

## 開けない・うまく動かないとき

- zip を解凍済みか、Chrome または Edge で開いているかを確認してください。
- ツールの画面で問題が起きた場合は、その画面に「もう一度表示する」が出ます。ほかのツールはそのまま使えます。
- ホームの右上の「i」（このアプリについて）で、版番号と使っているライブラリのライセンスを確認できます。
- 解決しない場合は、版番号、使っている OS・ブラウザー、行った操作、表示されたメッセージを配布元へ伝えてください。

開発・リリースの手順は [docs/development.md](docs/development.md) にあります。
