# toolbox

toolbox は、PC 上で使える便利ツールをまとめたものです。受け取った zip を解凍し、入口ページを Chrome または Edge で開いて使います。アプリのインストールは不要です。

## 使い始める

1. 配布された `toolbox-<版>.zip` を PC に保存します。
2. zip を解凍します。
3. 解凍したフォルダの `index.html` を Chrome または Edge で開きます。
4. ツールのカードの一覧から、使いたいツールを選びます。

各ツールの画面左上には、トップへ戻るボタン（家のマーク）、ツールのアイコンと名前、表示の切り替えボタン（月・太陽のマーク）が並びます。ツールから一覧に戻るときは家のマークを押してください。同じタブで入口ページに戻ります。

画面の色は、最初は PC のダークモードの設定に合わせて明るい表示と暗い表示が切り替わります。切り替えボタン（入口ページでは版番号の右）を押すと、明るい表示と暗い表示を選べます。選んだ表示は入口ページと全ツールで共通です。PC の設定と同じ表示に戻すと、以後は PC の設定に従います。印刷と、ローカルノートの HTML エクスポートは明るい表示で出力します。

zip の中から直接開かず、解凍してから使ってください。`index.html` と `tools` フォルダは一緒に置いておきます。別の場所へ移すときは、解凍したフォルダごと移してください。

## 使えるツール

| ツール | できること |
| --- | --- |
| [PDF編集](tools/pdf-edit/README.md#使い方) | PDF のページの削除・並べ替え・回転・結合、画像や文字の取り出し |
| [ローカルノート](tools/note-html/README.md#使い方) | PC のフォルダにある Markdown の閲覧・編集・保存、画像やファイルの添付 |
| [文字コード変換](tools/mojicode-converter/README.md#使い方) | 文字と文字コードの値（Unicode の番号・UTF-8・UTF-16・Shift_JIS）の相互変換、文字の素性・表記の形の確認 |
| [プロンプト集](tools/prompt-library/README.md#使い方) | よく使う AI チャットのプロンプトの保存・編集、タグでの絞り込み、ボタンひとつでのコピー |
| [タイピングゲーム](tools/typing-game/README.md#使い方) | 貼り付けた文章を見本にした日本語入力の練習、かかった時間と見本と違う箇所の確認 |

PDF編集では、元の PDF を上書きせず、編集結果を別のファイルとして保存します。PDF やその内容を外部へ送信しません。

ローカルノートでは、選んだフォルダの Markdown を直接編集し、「保存」で元のファイルに書き込みます。ノートや添付を外部へ送信しません。トップへ戻る前に、残したい変更を保存してください。

文字コード変換では、入力した文字をこのPC内で計算し、外部へ送信しません。入力内容は保存しないため、トップへ戻ると消えます。

プロンプト集では、プロンプトを自分で選んだフォルダの `prompt-library.json` に保存します。追加・編集・削除は、その操作を確定した時点でファイルに書き込みます。プロンプトを外部へ送信しません。

タイピングゲームでは、貼り付けた文章と打った文章をこのPC内で照らし合わせ、外部へ送信しません。文章も結果も保存しないため、トップへ戻ると消えます。

## 利用できる環境

- Windows または Mac
- Chrome または Edge 129 以降（最新の安定版を推奨。Safari は対象外）

ネット接続なしで使える構成です。ただし、会社 PC での動作と、対象環境での完全オフライン利用は確認中です。

## 版の確認と更新

入口ページの上部と各ツールの右下に、`2026.09.26` のような版番号が表示されます。同じ日に複数の版が出た場合は、`2026.09.26.2` のように末尾に番号が付きます。

新しい版を受け取ったら、作業結果をファイルに保存してから、新しい zip を解凍し、その中の `index.html` を開いてください。版ごとにフォルダが分かれるので、古い版に上書きする必要はありません。自動更新は行いません。

PDF編集でブラウザー内に保存した作業状態は、新しい版では引き継げない場合があります。必要な PDF は、切り替える前に「PDFを保存」で保存してください。

ローカルノートも、切り替える前に本文を保存してください。新しい版ではフォルダの選択や表示設定をやり直す場合がありますが、保存済みのノートと添付は元のフォルダに残ります。

プロンプト集のプロンプトは選んだフォルダに残るため、新しい版でも同じフォルダを選べば続けて使えます。新しい版で前回のフォルダが表示されない場合は、同じフォルダを選び直してください。

## 開けない・うまく動かないとき

- zip を解凍済みか、Chrome または Edge で開いているかを確認してください。
- 一覧からツールを開けない場合は、`index.html` と `tools` フォルダが同じ場所にあるかを確認してください。
- 解決しない場合は、版番号、使っている OS・ブラウザー、行った操作、表示されたメッセージを配布元へ伝えてください。
